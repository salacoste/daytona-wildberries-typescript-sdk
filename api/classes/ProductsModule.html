Окончательно удалить карточки товаров из корзины

Permanently delete product cards from trash (irreversible). Frees up limit slots immediately, bypassing the 30-day auto-cleanup. Complement to createDeleteTrash() (soft, move to trash) — call this when you want to recover limit slots NOW.

Sandbox-only at v3.13.1 release (2026-05-15): WB announced this endpoint in the Sandbox environment. Production availability is tracked via WL-5 in backlog/watch-list.md. When WB confirms production release, this JSDoc marker will drop in a patch release.

  }
