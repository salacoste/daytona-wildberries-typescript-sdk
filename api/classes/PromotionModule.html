Бюджеты кампаний (V2)

Метод возвращает информацию о бюджетах сразу нескольких кампаний — максимальной сумме затрат на кампанию.

Бюджет возвращается только для кампаний в статусах:

  • 4 — готова к запуску
  • 9 — активна
  • 11 — на паузе

Поле total указывается в БАЗОВЫХ единицах валюты кабинета продавца — НЕ в минорных (не в копейках). Если по кампании нет данных, соответствующий элемент adverts — null.

Заменяет метод PromotionModule.getAdvBudget (GET /adv/v1/budget), который WB отключит 16 ноября 2026 года.

Rate limit: 20 requests per minute, 3s interval, burst 4 (Personal/Service tokens)
