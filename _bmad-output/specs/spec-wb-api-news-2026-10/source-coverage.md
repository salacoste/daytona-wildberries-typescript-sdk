# Источники, покрытие и доказательства

## Правила доказательств

- **Official contract:** официальные announcement/operation URL WB остаются controlling sources; закреплённый публичный third-party OpenAPI snapshot — только supplemental non-official evidence и не называется официальной ревизией.
- **Official raw capture:** публичные raw Swagger `02-items`, `13-finances` и `05-dbs` получены 2026-10-11 по HTTP 200; URL mutable, поэтому датированные SHA-256 и JSONPath фиксируют наблюдение, но не являются immutable revision или runtime proof. Полный отчёт: [`wb-api-news-2026-10-official-raw-contracts.md`](../../../backlog/docs/wb-api-news-2026-10-official-raw-contracts.md).
- **Repository proof:** текущий символ, локальный OpenAPI, тест или документация в HEAD.
- **Verification proof:** свежий exit result целевого теста, type-check, lint, OpenAPI validation и declaration/package build smoke.
- **Release history:** существующие записи о ранее опубликованной версии подтверждают только прошлую публикацию, а не текущий runtime.
- **Network attempt:** ранняя ошибочная integration-команда загрузила существующее dotenv-состояние; 228 mocked checks прошли, 1 test был skipped, а 8 live checks завершились `NetworkError`. Попытка не доказала поведение WB runtime; значения токенов не сохраняются и не сообщаются.
- **Successful live runtime:** отсутствует. После исправления live-файл выбирается только точным `WB_LIVE_API_TESTS=true` и проверяет flag до импорта dotenv; повторный live-запуск не выполняется.
