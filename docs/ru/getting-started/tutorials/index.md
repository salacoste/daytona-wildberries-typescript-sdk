# Руководства

Подробные пошаговые руководства для освоения Wildberries TypeScript SDK.

> **English Version** | [Русская версия](../../../getting-started/tutorials/)

## Обзор

Эти руководства помогут вам создавать реальные e-commerce решения для маркетплейса Wildberries. Каждое руководство включает полные рабочие примеры кода, которые вы можете использовать как основу для своих проектов.

---

## Доступные руководства

### 1. Синхронизация каталога товаров

**[Начать руководство →](./product-catalog-sync.md)**

Узнайте, как синхронизировать каталог товаров с маркетплейсом Wildberries.

- Получение категорий товаров из Wildberries
- Создание карточек товаров с атрибутами
- Загрузка медиафайлов (изображений)
- Динамическое обновление цен

**Время:** 30 минут | **Сложность:** Начальный уровень

---

### 2. Обработка заказов

**[Начать руководство →](./order-fulfillment.md)**

Создайте полный рабочий процесс обработки заказов FBS (Fulfillment by Seller).

- Получение новых заказов из Wildberries
- Обновление статусов заказов
- Генерация этикеток и стикеров для отправки
- Управление поставками

**Время:** 45 минут | **Сложность:** Средний уровень

---

### 3. Панель аналитики

**[Начать руководство →](./analytics-dashboard.md)**

Создайте комплексную панель аналитики с данными о продажах, запасах и показателях эффективности.

- Агрегация данных о продажах и расчёт KPI
- Отслеживание уровня запасов на складах
- Мониторинг возвратов и отзывов клиентов
- Генерация отчётов в различных форматах

**Время:** 60 минут | **Сложность:** Средний уровень

---

### 4. Мультимодульная интеграция

**[Начать руководство →](./multi-module-integration.md)**

Создайте продвинутую систему, интегрирующую несколько модулей SDK для сложных бизнес-процессов.

- Объединение модулей Products, Orders, Analytics и Reports
- Реализация межмодульных конвейеров данных
- Обработка ошибок и повторов между модулями
- Создание надёжных автоматизированных рабочих процессов

**Время:** 90 минут | **Сложность:** Продвинутый уровень

---

## Предварительные требования

Перед началом любого руководства убедитесь, что у вас есть:

- ✅ **Node.js ≥ 20.0.0** установлен
- ✅ **Аккаунт продавца Wildberries** с доступом к API
- ✅ **SDK установлен** через `npm install daytona-wildberries-typescript-sdk`
- ✅ **Базовые знания TypeScript**
- ✅ Пройден [Быстрый старт](../quickstart.md)

---

## Подход к обучению

Каждое руководство следует единой структуре:

1. **Что вы создадите** - Обзор конечного результата
2. **Цели обучения** - Навыки, которые вы получите
3. **Предварительные требования** - Что нужно перед началом
4. **Пошаговые инструкции** - Детальное руководство по реализации
5. **Полный код** - Полностью рабочий пример
6. **Следующие шаги** - Куда двигаться дальше

---

## Рекомендуемый путь обучения

Для лучшего освоения материала рекомендуем проходить руководства по порядку:

```
1. Синхронизация каталога товаров (Начальный)
       ↓
2. Обработка заказов (Средний)
       ↓
3. Панель аналитики (Средний)
       ↓
4. Мультимодульная интеграция (Продвинутый)
```

Каждое руководство основывается на концепциях из предыдущих, помогая вам постепенно освоить SDK.
