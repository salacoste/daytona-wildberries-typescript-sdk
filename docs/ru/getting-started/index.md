# Начало работы

Новичок в Wildberries TypeScript SDK? Этот раздел поможет вам быстро начать работу.

## Быстрые ссылки

- **[Быстрый старт](/ru/getting-started/quickstart)** - Сделайте свой первый API-вызов за 5 минут
- **[Учебные руководства](/ru/getting-started/tutorials/)** - Пошаговые руководства для распространенных рабочих процессов

## Предварительные требования

- Node.js ≥ 20.0.0
- npm ≥ 10.0.0
- API ключ Wildberries ([получить здесь](https://seller.wildberries.ru/))

## Следующие шаги

1. [Завершите быстрый старт](/ru/getting-started/quickstart)
2. Попробуйте [учебное руководство](/ru/getting-started/tutorials/) для вашего случая использования
3. Изучите [справочник API](/api/)
