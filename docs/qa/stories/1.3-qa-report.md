### Error Transformation
**Rating**: ⭐⭐⭐⭐⭐ Excellent

**HTTP Status Code Mapping**:
```typescript
private transformError(error: AxiosError): WBAPIError {
  const status = error.response?.status;

  if (status === 401 || status === 403) {
    return new AuthenticationError(message, status, response, requestId);
  }

  if (status === 429) {
    const retryAfter = parseRetryAfter(error.response.headers);
    return new RateLimitError(message, retryAfter, response, requestId);
  }

  if (status === 400 || status === 422) {
    const fieldErrors = parseFieldErrors(response);
    return new ValidationError(message, fieldErrors, status, response, requestId);
  }

  if (error.code === 'ECONNABORTED' || error.code === 'ETIMEDOUT') {
    return new NetworkError(message, true, undefined, error, response, requestId);
  }

  if (status && status >= 500) {
    return new NetworkError(message, false, status, error, response, requestId);
  }

  return new WBAPIError(message, status, response, requestId);
}
```

**Quality Highlights**:

- ✅ Retry-After header parsing
- ✅ Field errors extraction
- ✅ Request ID preservation
- ✅ Fallback to base WBAPIError
