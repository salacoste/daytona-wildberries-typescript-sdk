# Story 10.1: Web API Foundation & Gem Subscription Check

**Epic:** [Epic 10: Web API Module](../epics/epic-10-web-api-module.md)
**Status:** 🟡 Draft | Planned
**Priority:** HIGH

## Description

Создать фундамент для работы с **неофициальными Web API** Wildberries и реализовать первый метод — проверку статуса подписки "Джем" (Gem Subscription).

Этот модуль позволит SDK получать доступ к функционалу, который недоступен через официальную OpenAPI документацию, используя JWT токен веб-сессии вместо API ключа.

---

## Business Value

### Проблема

Официальный Wildberries API (документированный в OpenAPI спецификациях) не предоставляет:
- Методов для проверки статуса подписки "Джем"
- Доступа к некоторым функциям веб-интерфейса
- Интеграции с веб-специфичными endpoints

### Решение

Создать **отдельный модуль** `WebApiModule`, который:
1. Использует JWT токен веб-авторизации
2. Предоставляет метод проверки подписки "Джем"
3. Служит фундаментом для будущих Web API интеграций
4. Явно предупреждает о рисках использования недокументированных API

### Phase 2: WebApiModule Implementation

```typescript
// src/modules/web-api/index.ts
import { WebApiClient } from '../../client/web-client';
import type { GemSubscriptionStatus, WebApiConfig } from '../../types/web-api.types';

/**
 * Web API Module — Работа с неофициальными Web API endpoints
 *
 * @experimental Этот модуль работает с недокументированными API,
 * которые могут измениться в любой момент без уведомления.
 *
 * @warning Используйте на свой риск. Нет обратной совместимости.
 * Токен НЕ хранится в модуле — передаётся каждым вызовом.
 *
 * @example
 * ```typescript
 * const webModule = new WebApiModule();
 *
 * const subscription = await webModule.checkGemSubscription({
 *   jwtToken: getWebSessionToken()
 * });
 *
 * if (subscription.hasSubscription) {
 *   console.log('Gem active until:', subscription.expiryDate);
 * }
 * ```
 */
export class WebApiModule {
  private client: WebApiClient;

  constructor(config?: WebApiConfig) {
    this.client = new WebApiClient(config);
  }

  /**
   * Проверка статуса подписки "Джем" (Gem Subscription)
   *
   * @param jwtToken - JWT токен из веб-сессии (authorizev3 header)
   * @returns Статус подписки с деталями
   * @throws {WebApiError} При изменении формата ответа
   * @throws {AuthenticationError} При недействительном токене
   *
   * @example
   * ```typescript
   * const status = await webModule.checkGemSubscription({
   *   jwtToken: 'eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...'
   * });
   * ```
   */
  async checkGemSubscription(options: {
    jwtToken: string;
  }): Promise<GemSubscriptionStatus> {
    return this.client.get<GemSubscriptionStatus>(
      '/ns/subscriptions-api/monetization/api/v1/subscriptions',
      {
        headers: {
          'authorizev3': options.jwtToken
        }
      }
    );
  }
}
```

   /**
    * Извлечение JWT токена из веб-сессии Wildberries

    * Этот пример показывает, как получить authorizev3 токен из браузера.
    *
    * Методы извлечения:

    */

   import puppeteer from 'puppeteer';

   async function getWildberriesWebToken(): Promise<string> {
     const browser = await puppeteer.launch();
     const page = await browser.newPage();

     // Login to seller portal
     await page.goto('https://seller.wildberries.ru');
     // ... perform login ...

     // Extract token from network requests
     const token = await page.evaluate(() => {
       return localStorage.getItem('x-supplier-id');
     });

     await browser.close();
     return token;
   }
   ```

## Technical Specifications

### Endpoint Details

**Method:** `GET /ns/subscriptions-api/monetization/api/v1/subscriptions`

**Base URL:** `https://seller.wildberries.ru`

**Authentication:**
```http
authorizev3: eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...
```

**Expected Response:**
```json
{
  "data": {
    "hasSubscription": true,
    "subscriptionType": "gem",
    "expiryDate": "2025-12-31T23:59:59Z",
    "autoRenew": true,
    "trialDaysRemaining": 0,
    "features": [
      {
        "id": "extended_analytics",
        "name": "Расширенная аналитика",
        "enabled": true
      }
    ]
  }
}
```

**Error Responses:**

| Status Code | Description |
|-------------|-------------|
| 401 | Недействительный JWT токен |
| 403 | Доступ запрещён |
| 429 | Слишком много запросов |
| 500 | Ошибка сервера |
