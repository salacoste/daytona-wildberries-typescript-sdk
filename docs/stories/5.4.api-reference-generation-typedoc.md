## Story

**As a** developer integrating the SDK,
**I want** a comprehensive, searchable API reference generated from source code,
**so that** I can quickly find method signatures, parameters, return types, and examples without reading source files.

## Dev Notes

### TypeDoc Configuration

**typedoc.json:**
```json
{
  "$schema": "https://typedoc.org/schema.json",
  "entryPoints": ["src/index.ts"],
  "entryPointStrategy": "expand",
  "out": "docs/api",
  "plugin": [
    "typedoc-plugin-missing-exports"
  ],
  "exclude": [
    "**/*.test.ts",
    "**/*.spec.ts",
    "**/node_modules/**"
  ],
  "excludePrivate": true,
  "excludeProtected": true,
  "excludeInternal": true,
  "readme": "README.md",
  "includeVersion": true,
  "sort": ["source-order"],
  "categorizeByGroup": true,
  "navigation": {
    "includeCategories": true,
    "includeGroups": true
  },
  "searchInComments": true,
  "visibilityFilters": {
    "protected": false,
    "private": false,
    "inherited": true,
    "external": false
  }
}
```

**package.json scripts:**
```json
{
  "scripts": {
    "docs:api": "typedoc",
    "docs:api:watch": "typedoc --watch",
    "docs:validate": "typedoc --emit docs --dry-run"
  }
}
```

### JSDoc Enhancement Standards

**Complete JSDoc Example:**

```typescript
/**
 * Fetches all parent categories for product creation.
 *
 * Parent categories are top-level product classifications in the Wildberries
 * catalog (e.g., "Electronics", "Household chemicals"). Use this method to
 * get the list of available categories before creating a product card.
 *
 * **Rate Limit:** 1 request per 10 seconds
 *
 * @returns Promise resolving to list of parent categories with IDs and names
 *
 * @throws {AuthenticationError} When API key is invalid or missing
 * @throws {RateLimitError} When rate limit exceeded (429 status)
 * @throws {NetworkError} When network connection fails
 *
 * @example
 * ```typescript
 * const categories = await sdk.products.getParentCategories();
 * console.log(categories.data);
 * // Output: [{ id: 1, name: 'Electronics' }, ...]
 * ```
 *
 * @see {@link https://dev.wildberries.ru/openapi/work-with-products#tag/Kategorii-predmety-i-harakteristiki}
 * @see {@link ProductsModule.getCategories} for child categories
 */
async getParentCategories(): Promise<GetCategoriesResponse> {
  return this.client.get<GetCategoriesResponse>(
    'https://content-api.wildberries.ru/content/v2/object/parent/all'
  );
}
```

**JSDoc Tag Usage:**

| Tag | Purpose | Required |
|-----|---------|----------|
| `@description` | Method purpose and behavior | ✅ Yes |
| `@param` | Parameter description and type | ✅ Yes (if params) |
| `@returns` | Return value description | ✅ Yes |
| `@throws` | Error conditions | ✅ Yes (document all) |
| `@example` | Working code example | ✅ Yes (all public methods) |
| `@see` | Related methods/docs | ⚠️ Recommended |
| `@link` | External references | ⚠️ Recommended |
| `@deprecated` | Deprecated methods | ✅ Yes (if deprecated) |
| `@since` | Version introduced | ⚠️ Optional |
| `@category` | Group methods | ⚠️ Optional |

### Search Optimization

**TypeDoc Search Features:**

1. **Indexed Content:**
   - Class names
   - Method names
   - Property names
   - Parameter names
   - JSDoc description text
   - Example code (if `searchInComments: true`)

2. **Search Ranking:**
   - Exact matches ranked highest
   - Partial matches ranked by relevance
   - Search in headings > descriptions > code

3. **Search Performance:**
   - Client-side search (no server required)
   - Lunr.js powered indexing
   - Optimized for ~1000 methods (our scale: ~300 methods)

**Configuration:**
```json
{
  "searchInComments": true,
  "searchInShortcuts": true,
  "searchGroupBoosts": {
    "Classes": 1.5,
    "Functions": 1.2
  }
}
```

### CI/CD Integration

**GitHub Actions Workflow Addition:**

```yaml
# .github/workflows/ci.yml

jobs:
  build-and-test:
    # ... existing jobs

  generate-docs:
    name: Generate API Documentation
    runs-on: ubuntu-latest
    needs: build-and-test
    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: Validate JSDoc coverage
        run: npm run docs:validate

      - name: Generate API docs
        run: npm run docs:api

      - name: Check for documentation warnings
        run: |
          if grep -r "warning" docs/api/; then
            echo "⚠️ TypeDoc generated warnings"
            exit 1
          fi

      - name: Upload API docs artifact
        uses: actions/upload-artifact@v3
        with:
          name: api-docs
          path: docs/api/

      # Optional: Deploy to GitHub Pages
      - name: Deploy to GitHub Pages
        if: github.ref == 'refs/heads/main'
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./docs/api
          destination_dir: api
```
