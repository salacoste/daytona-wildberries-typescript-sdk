# Story 1.10: Main SDK Class and Module Aggregation

---

## Status

**Ready for Review**

---

## Story

**As a** SDK user,
**I want** a single entry point to access all SDK functionality,
**so that** I can initialize once and use multiple modules seamlessly.

---

## Acceptance Criteria

1. `WildberriesSDK` main class created in `src/index.ts`
2. Constructor accepts `SDKConfig` with API key and optional configuration
3. `BaseClient` instance created and shared across all modules
4. `general` property exposes `GeneralModule` instance
5. Placeholder properties for remaining 10 modules (to be implemented in future epics)
6. Main class exports all types, errors, and modules from single import
7. Tree-shaking validated: importing only `WildberriesSDK` with General module results in minimal bundle
8. TypeScript declarations (.d.ts) generated for full IDE autocomplete
9. README quickstart guide enables API call in <30 minutes
10. Integration test validates end-to-end flow: `new WildberriesSDK({ apiKey }) → sdk.general.ping()`

### Architecture Overview

**Source:** [docs/architecture.md - Components Section]

**WildberriesSDK Class** is the **primary entry point** and **SDK Aggregator Layer** (Layer 4 of architecture).

**Responsibility:** Aggregates all 11 API modules and provides single configuration point.

**Location:** `src/index.ts`

**Architecture Pattern:** Facade Pattern with Dependency Injection
- Main SDK class delegates to modules
- Modules delegate to shared BaseClient
- Single configuration object passed to all layers

### Module Integration Pattern

**Source:** [docs/architecture.md - Module Organization Pattern]

**Pattern:** Facade Pattern with Delegation

**Implementation:**
1. Constructor receives SDKConfig
2. Create **single** BaseClient instance from config
3. Pass same BaseClient instance to **all** module constructors
4. Modules delegate all HTTP operations to BaseClient
5. BaseClient applies rate limiting, retry, auth, error handling uniformly

**Example Constructor Logic:**
```typescript
constructor(config: SDKConfig) {
  // Validate API key
  if (!config.apiKey || config.apiKey.trim() === '') {
    throw new AuthenticationError('API key is required');
  }

  // Create shared BaseClient
  const baseClient = new BaseClient(config);

  // Initialize modules with shared client
  this.general = new GeneralModule(baseClient);
  // Future: this.products = new ProductsModule(baseClient);
  // ... initialize other modules
}
```

### Coding Standards

**Source:** [docs/architecture.md - Coding Standards]

1. **Zero `any` Types** - Never use `any` except controlled error handling
2. **All Public Methods Require JSDoc** - With @param, @returns, @throws, @example
3. **Errors Must Be Typed** - Never throw strings or plain objects
4. **No Direct Axios Usage in SDK Class** - Use BaseClient only
5. **No Secrets in Code** - API key from config only

- **Class:** `WildberriesSDK` (PascalCase)
- **Interface:** `SDKConfig` (PascalCase)
- **Properties:** `readonly general` (camelCase)
