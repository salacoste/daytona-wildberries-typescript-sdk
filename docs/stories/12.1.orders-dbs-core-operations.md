## Context

### Background

Orders DBS (Delivery by Seller) is a fulfillment model where sellers handle both storage AND delivery directly to customers. Unlike FBS (where WB delivers to pickup points) or FBW (where WB stores and delivers), DBS gives sellers full control over the delivery process.

**Key DBS Characteristics**:
- **Direct Delivery**: Seller delivers to customer's address (not pickup points)
- **Customer Contact**: Access to customer phone and full address with coordinates
- **Delivery Windows**: Specific delivery date/time windows (dTimeFrom, dTimeTo)
- **Required Metadata**: Orders may require IMEI, UIN, GTIN, SGTIN, or customs declarations
- **Delivery Type**: Always `deliveryType: 'dbs'`

**Business Value**:
- Enable sellers to manage their own delivery fleet
- Access customer location data for route optimization
- Support compliance requirements via requiredMeta field
- Foundation for complete DBS order lifecycle management

### Technical Context

**API Documentation**: `wildberries_api_doc/04-orders-dbs.yaml`

**Base URL**: `https://marketplace-api.wildberries.ru`

**Key OpenAPI Paths**:
```yaml
GET  /api/v3/dbs/orders/new    - Get new assembly tasks
GET  /api/v3/dbs/orders        - Get completed orders (with pagination)
POST /api/v3/dbs/orders/client - Get customer contact information
```

### Task 3: OrdersDbsModule Implementation - getOrders
**Acceptance Criteria**: 3, 6, 8

- [ ] Implement getOrders() with pagination and date filtering:
  ```typescript
  /**
   * Get completed DBS orders with pagination and date filtering
   *
   * Returns orders that have been completed (delivered or cancelled).
   * Maximum 30 calendar days per request.
   *
   * Rate limit: 300 requests/min, 200ms interval, 20 burst
   *
   * @param params - Query parameters
   * @param params.limit - Number of orders to return (1-1000)
   * @param params.next - Pagination cursor (0 for first request)
   * @param params.dateFrom - Start date as Unix timestamp
   * @param params.dateTo - End date as Unix timestamp
   * @returns Promise resolving to orders and next cursor
   * @throws {ValidationError} When parameters are invalid
   * @throws {RateLimitError} When rate limit exceeded
   *
   * @example
   * ```typescript
   * // Get orders from last 7 days
   * const now = Math.floor(Date.now() / 1000);
   * const weekAgo = now - 7 * 24 * 60 * 60;
   *
   * let next = 0;
   * do {
   *   const result = await sdk.ordersDBS.getOrders({
   *     limit: 100,
   *     next,
   *     dateFrom: weekAgo,
   *     dateTo: now
   *   });
   *   console.log(`Fetched ${result.orders.length} orders`);
   *   next = result.next;
   * } while (next > 0);
   * ```
   */
  async getOrders(params: GetOrdersParams): Promise<GetOrdersResponse> {
    // Validation
    if (params.limit < 1 || params.limit > 1000) {
      throw new ValidationError('limit must be between 1 and 1000');
    }
    if (params.next < 0) {
      throw new ValidationError('next must be >= 0');
    }
    // Check 30-day max range
    const maxRange = 30 * 24 * 60 * 60;
    if (params.dateTo - params.dateFrom > maxRange) {
      throw new ValidationError('Date range cannot exceed 30 days');
    }

    return this.client.get<GetOrdersResponse>(
      'https://marketplace-api.wildberries.ru/api/v3/dbs/orders',
      {
        params: {
          limit: params.limit,
          next: params.next,
          dateFrom: params.dateFrom,
          dateTo: params.dateTo
        },
        rateLimitKey: 'orders-dbs.getOrders'
      }
    );
  }
  ```

  /**
   * Get customer contact information for DBS orders
   *
   * Returns customer name, phone number, and additional contact codes.
   * Use this to contact customers for delivery coordination.
   *
   * Rate limit: 300 requests/min, 200ms interval, 20 burst
   *
   * @param orderIds - Array of order IDs to get client info for
   * @returns Promise resolving to customer contact information
   * @throws {ValidationError} When orderIds array is empty
   * @throws {NotFoundError} When order not found (404)
   * @throws {RateLimitError} When rate limit exceeded
   *
   * @example
   * ```typescript
   * const clientInfo = await sdk.ordersDBS.getClientInfo([123456, 234567]);

   *   console.log(`  Phone: +${client.phoneCode}${client.phone}`);

  async getClientInfo(orderIds: number[]): Promise<GetClientInfoResponse> {
    if (!orderIds || orderIds.length === 0) {

    return this.client.post<GetClientInfoResponse>(
      'https://marketplace-api.wildberries.ru/api/v3/dbs/orders/client',
      { orders: orderIds },
      { rateLimitKey: 'orders-dbs.getClientInfo' }

### DBS vs FBS vs FBW Comparison

**FBS (Fulfillment by Seller)**:
- Seller stores products
- WB delivers to pickup points
- Customer picks up at WB point

**FBW (Fulfillment by Wildberries)**:
- WB stores products
- WB delivers to customers
- Seller ships to WB warehouse

**DBS (Delivery by Seller)** - This Story:
- Seller stores products
- Seller delivers directly to customer
- Customer receives at home address
- Seller has access to full address + phone

### Key DBS-Specific Features

1. **Customer Address Access**: Full address with GPS coordinates
2. **Delivery Windows**: Specific time slots (dTimeFrom, dTimeTo)
3. **Required Metadata**: `requiredMeta` array tells what compliance data is needed
