# 8.3: Promotion Module - Type Definitions Fix

## Status

**✅ COMPLETED** - December 2024

---

## Summary

Fixed critical TypeScript type definitions in the Promotion module:
1. **`getStatsKeywords()`** - Changed parameters from optional to required (matching API contract)
2. **`placement_types` arrays** - Fixed union type syntax from `'a' | 'b'[]` to `('a' | 'b')[]`

---

## Background

During comprehensive testing of the Promotion module (29 methods), two type-related issues were discovered:

1. **API Contract Mismatch**: `getStatsKeywords()` declared parameters as optional, but the Wildberries API requires all three parameters (`advert_id`, `from`, `to`)

2. **TypeScript Operator Precedence**: Array type definitions used incorrect syntax. In TypeScript:
   - `'a' | 'b'[]` means `'a' | ('b'[])` - union of string OR array
   - `('a' | 'b')[]` means array of strings - **correct**

**API Documentation**: https://dev.wildberries.ru/openapi/work-with-advertising

## Type Definition Explanation

### Why `('a' | 'b')[]` vs `'a' | 'b'[]`?

TypeScript follows standard operator precedence where `[]` binds tighter than `|`:

```typescript
// WRONG: Union of string OR array of strings
type Wrong = 'search' | 'recommendation'[];
// Equivalent to: 'search' | ('recommendation'[])
// Allows: 'search' or ['recommendation', 'recommendation', ...]
// Does NOT allow: ['search', 'recommendation']

// CORRECT: Array of union strings
type Correct = ('search' | 'recommendation')[];
// Allows: ['search'], ['recommendation'], ['search', 'recommendation']
```

## Usage Example

```typescript
import { WildberriesSDK } from 'daytona-wildberries-typescript-sdk';

const sdk = new WildberriesSDK({ apiKey: process.env.WB_API_KEY! });

// Get keyword statistics (all parameters now required)
async function getKeywordStats(campaignId: number) {
  const today = new Date();
  const weekAgo = new Date(today.getTime() - 7 * 24 * 60 * 60 * 1000);

  const formatDate = (d: Date) => d.toISOString().split('T')[0];

  const stats = await sdk.promotion.getStatsKeywords({
    advert_id: campaignId,
    from: formatDate(weekAgo),
    to: formatDate(today)
  });

  // Process keyword statistics
  stats.keywords?.forEach(day => {
    console.log(`Date: ${day.date}`);
    day.stats?.slice(0, 5).forEach(kw => {
      console.log(`  ${kw.keyword}: ${kw.views} views, ${kw.clicks} clicks`);
    });
  });
}

// Create bid request with correct array type
async function getMinimumBids(campaignId: number, productIds: number[]) {
  const result = await sdk.promotion.createBidsMin({
    advert_id: campaignId,
    nm_ids: productIds,
    payment_type: 'cpm',
    placement_types: ['search', 'recommendation'] // Now correctly typed as array
  });

  return result.bids;
}
```
