## Validation Process Instructions

### Phase 1: Documentation Analysis (Per File)

For each of the 11 OpenAPI files:

1. **File Selection**: User specifies which documentation file to analyze
2. **Structured Analysis**: If file is large (>50 endpoints), split into logical sections
3. **Endpoint Inventory**: Create comprehensive list of all documented endpoints
4. **Implementation Comparison**: Check each endpoint against current code:
   - ✅ Implemented and matches specification
   - ❌ Missing from implementation
   - ⚠️ Implemented but may have issues

### Phase 2: Real-world Testing

For each implemented endpoint:

1. **Authentication Setup**: Use `.env` WB_API_KEY for real API access
2. **Endpoint Testing**: Execute actual API calls
3. **Response Validation**: Verify:
   - Successful HTTP response (200/201)
   - Expected data structure returned
   - Rate limits respected
   - Error handling works correctly

### Phase 3: Issue Documentation

Document two types of problems:

**Type A: Missing Implementation**
```
❌ MISSING: [module].[method]()
Documentation: OpenAPI endpoint [path] with [method]
Location: docs/wildberries_api_doc/[file].yaml
Priority: HIGH/MEDIUM/LOW
Impact: Business function description
```

**Type B: Implementation Issues**
```
⚠️ BROKEN: [module].[method]()
Documentation: OpenAPI endpoint [path] with [method]
Error: [Actual error message from real API call]
Expected: [What should happen according to documentation]
Priority: CRITICAL/HIGH/MEDIUM/LOW
Status: [Investigation needed / Fix required / Working]
```

### Test Execution Pattern

```typescript
// Real API validation pattern for each endpoint
import { WildberriesSDK } from '../../src';

const sdk = new WildberriesSDK({
  apiKey: process.env.WB_API_KEY!
});

async function testEndpoint(methodName: string, apiCall: () => Promise<any>) {
  try {
    console.log(`🧪 Testing: ${methodName}`);
    const result = await apiCall();
    console.log(`✅ SUCCESS: ${methodName}`);
    console.log(`📊 Result type: ${typeof result}`);
    console.log(`📦 Keys: ${Object.keys(result).join(', ')}`);
    return { status: 'success', result };
  } catch (error) {
    console.log(`❌ FAILED: ${methodName}`);
    console.log(`🚨 Error: ${error.message}`);
    if (error.response) {
      console.log(`📡 HTTP Status: ${error.response.status}`);
      console.log(`📄 Response: ${JSON.stringify(error.response.data, null, 2)}`);
    }
    return { status: 'failed', error };
  }
}
```
