## User Story

**As a** пользователь SDK,
**I want** проверить доступные опции приёмки для конкретных товаров,
**so that** я могу узнать на какие склады и с каким типом упаковки можно отправить товары.

---

## Business Context

Перед созданием поставки продавцу необходимо:
- Проверить доступность складов для конкретных баркодов
- Узнать доступные типы упаковки: короба, монопаллеты, суперсейф
- Получить информацию об ошибках для невалидных баркодов

---

## Technical Specification

### API Endpoint

```
POST https://supplies-api.wildberries.ru/api/v1/acceptance/options
```

**Query Parameters:**
- `warehouseID` (optional) — Фильтр по ID склада

**Request Body:**
```typescript
interface ModelsGood {
  barcode: string;   // Баркод товара
  quantity: number;  // Количество (1-999999)
}
```

**Rate Limit:** 6 req/min, интервал 10 секунд

### Response Schema

```typescript
interface ModelsOptionsResultModel {
  result?: Array<{
    barcode?: string;
    error?: {
      title?: string;
      detail?: string;
    };
    isError?: boolean;
    warehouses?: Array<{
      warehouseID?: number;
      canBox?: boolean;
      canMonopallet?: boolean;
      canSupersafe?: boolean;
    }> | null;
  }>;
  requestId?: string;
}
```

## Example Usage

```typescript
import { WildberriesSDK } from 'wb-api-sdk';

const sdk = new WildberriesSDK({ apiKey: 'your-api-key' });

// 1. Проверить опции для товаров
const options = await sdk.ordersFbw.createAcceptanceOption([
  { barcode: '2000000000015', quantity: 100 },
  { barcode: '2000000000022', quantity: 50 }
]);

// 2. Проверить конкретный склад
const krasnodarOptions = await sdk.ordersFbw.createAcceptanceOption(
  [{ barcode: '2000000000015', quantity: 100 }],
  { warehouseID: '218623' }
);

// 3. Обработка результатов
options.result?.forEach(item => {
  if (item.isError) {
    console.log(`Ошибка для ${item.barcode}: ${item.error?.detail}`);
  } else {
    console.log(`${item.barcode} доступен на складах:`);
    item.warehouses?.forEach(wh => {
      const types = [];
      if (wh.canBox) types.push('Короба');
      if (wh.canMonopallet) types.push('Монопаллеты');
      if (wh.canSupersafe) types.push('Суперсейф');
      console.log(`  - Склад ${wh.warehouseID}: ${types.join(', ')}`);
    });
  }
});
```
