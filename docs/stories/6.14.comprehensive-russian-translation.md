### Code Example Translation Guidelines

**DO:**
- Translate comments to Russian: `// Initialize SDK` → `// Инициализация SDK`
- Translate string literals for display: `"Error occurred"` → `"Произошла ошибка"`
- Translate inline documentation comments

**DON'T:**
- Modify variable names, function names, or API method names
- Translate keywords: `const`, `async`, `await`, `try`, `catch`, `if`, `else`
- Translate technical terms in code: SDK, API, HTTP remain in English
- Change code structure or logic

// English version

### Common Translation Issues and Solutions

**Issue 1: Cyrillic characters display as ???**
- **Cause:** File not saved as UTF-8
- **Solution:** Verify file encoding is UTF-8 in editor settings

**Issue 2: VitePress build fails with "File not found"**
- **Cause:** Sidebar configuration references non-existent file
- **Solution:** Verify all sidebar links point to actual `.md` files in `docs/ru/`

**Issue 3: Language switching returns 404**
- **Cause:** Russian page doesn't exist at same path as English
- **Solution:** Ensure file paths match exactly (e.g., `/en/guides/setup.md` ↔ `/ru/guides/setup.md`)

**Issue 4: Code examples break syntax highlighting**
- **Cause:** Accidentally modified code syntax during translation
- **Solution:** Revert code to original, only translate comments

**Issue 5: Internal links lead to English pages**
- **Cause:** Links not updated to `/ru/` prefix
- **Solution:** Find and replace all internal links: `./` → `/ru/`, `/en/` → `/ru/`

**Issue 6: Technical terms inconsistent across pages**
- **Cause:** Translator didn't reference glossary
- **Solution:** Review TRANSLATION_GLOSSARY.md, update all instances
