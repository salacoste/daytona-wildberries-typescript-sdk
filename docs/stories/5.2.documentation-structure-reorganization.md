### File Migration Strategy

**Migration Principles:**
1. **Preserve Git History** - Use `git mv` instead of `cp` + `rm`
2. **Update Links First** - Minimize broken link duration
3. **Batch Commits** - One commit per directory migration
4. **Test Navigation** - Verify links after each batch

**Migration Commands:**
```bash
# Example: Move installation guide
git mv docs/installation.md docs/getting-started/installation.md

# Example: Move best practices guide
git mv docs/best-practices.md docs/guides/best-practices.md

# Commit with descriptive message
git commit -m "docs: reorganize documentation structure (Story 5.2)

- Move getting-started content to docs/getting-started/
- Move guides to docs/guides/
- Create index.md for each directory
- Preserve git history with git mv"
```

### Link Validation

**Tool Recommendation:** markdown-link-check

**Installation:**
```bash
npm install --save-dev markdown-link-check
```

**Configuration (.markdown-link-check.json):**
```json
{
  "ignorePatterns": [
    {
      "pattern": "^http://localhost"
    }
  ],
  "timeout": "5s",
  "retryOn429": true,
  "retryCount": 3,
  "fallbackRetryDelay": "30s",
  "aliveStatusCodes": [200, 206]
}
```

**Validation Script (scripts/validate-links.js):**
```javascript
#!/usr/bin/env node

const { execSync } = require('child_process');
const { readdirSync, statSync } = require('fs');
const { join } = require('path');

// Find all markdown files
function findMarkdownFiles(dir, fileList = []) {
  const files = readdirSync(dir);

  files.forEach(file => {
    const filePath = join(dir, file);
    if (statSync(filePath).isDirectory()) {
      if (!file.startsWith('.') && file !== 'node_modules') {
        findMarkdownFiles(filePath, fileList);
      }
    } else if (file.endsWith('.md')) {
      fileList.push(filePath);
    }
  });

  return fileList;
}

// Validate links in all markdown files
const markdownFiles = findMarkdownFiles('.');
let hasErrors = false;

markdownFiles.forEach(file => {
  console.log(`Checking links in ${file}...`);
  try {
    execSync(`npx markdown-link-check ${file}`, { stdio: 'inherit' });
  } catch (error) {
    hasErrors = true;
  }
});

if (hasErrors) {
  console.error('\n❌ Link validation failed - broken links detected');
  process.exit(1);
} else {
  console.log('\n✅ All links valid');
}
```

**Add to package.json:**
```json
{
  "scripts": {
    "validate:links": "node scripts/validate-links.js"
  }
}
```

**Add to CI (.github/workflows/ci.yml):**
```yaml
- name: Validate documentation links
  run: npm run validate:links
```

1. **Root Files:**
   - README.md - Update "Documentation" section
   - CONTRIBUTING.md - Update development guide links

2. **Community Files:**
   - .github/ISSUE_TEMPLATE/*.yml - Update documentation links
   - .github/pull_request_template.md - Update reference links

3. **Configuration:**
   - package.json - Update "homepage" and "docs" URLs

4. **Code Examples:**
   - examples/*.ts - Update JSDoc @see references

5. **Internal Documentation:**
   - Update relative links in existing docs

**Link Update Script (scripts/update-links.sh):**
```bash
#!/bin/bash

# Find and replace old doc paths with new paths
# Example: docs/installation.md -> docs/getting-started/installation.md

find . -type f -name "*.md" -not -path "./node_modules/*" -exec sed -i '' \
  's|docs/installation.md|docs/getting-started/installation.md|g' {} +

find . -type f -name "*.md" -not -path "./node_modules/*" -exec sed -i '' \
  's|docs/best-practices.md|docs/guides/best-practices.md|g' {} +

# Add more replacements as needed

echo "✅ Links updated - run 'npm run validate:links' to verify"
```
