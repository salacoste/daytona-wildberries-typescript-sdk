## Authentication Issues

### Issue: "Authentication failed"

**Error Message:**
```
AuthenticationError: Invalid API key
```

**Cause:** API key is invalid, missing, or incorrectly configured.

**Solution:**
1. Verify API key is set:
   ```bash
   echo $WB_API_KEY
   ```
2. Check key format (should be 64 characters)
3. Verify key is active in Wildberries seller dashboard
4. Ensure no extra whitespace or quotes

**Code Example:**
```typescript
// ❌ WRONG
const sdk = new WildberriesSDK({ apiKey: '' });

// ✅ CORRECT
const sdk = new WildberriesSDK({
  apiKey: process.env.WB_API_KEY!
});
```

---

## Rate Limit Issues

### Issue: "429 Too Many Requests"

**Error Message:**
```
RateLimitError: Rate limit exceeded (3 requests per minute)
```

**Cause:** Exceeded per-endpoint rate limit.

**Solution:**
1. SDK automatically retries - wait for automatic recovery
2. Check rate limits in [API documentation](...)
3. Implement request batching
4. Consider upgrading to higher tier

**Code Example:**
```typescript
try {
  const result = await sdk.products.create(data);
} catch (error) {
  if (error instanceof RateLimitError) {
    console.log(`Rate limited. Retry after ${error.retryAfter}ms`);
    // SDK handles retry automatically
  }
}
```

## Error Code Reference

| Code | Error | Cause | Solution |
|------|-------|-------|----------|
| 400 | Bad Request | Invalid request data | Check request parameters |
| 401 | Unauthorized | Invalid/missing API key | Verify API key |
| 403 | Forbidden | Insufficient permissions | Check API key permissions |
| 404 | Not Found | Resource doesn't exist | Verify resource ID |
| 429 | Too Many Requests | Rate limit exceeded | Wait for retry |
| 500 | Internal Server Error | API server error | Retry request |
| 503 | Service Unavailable | API temporarily down | Retry with backoff |
