### Coding Standards to Enforce

**Critical ESLint Rules:**
1. `@typescript-eslint/no-explicit-any: error` - Zero `any` types allowed
2. `@typescript-eslint/no-unused-vars: error` - No unused variables
3. `no-console: warn` - No console.log in source code

**Naming Conventions:**
- Classes/Interfaces: PascalCase
- Functions/Variables: camelCase
- Constants: SCREAMING_SNAKE_CASE
- Files/Directories: kebab-case

### CI/CD Pipeline Requirements

**GitHub Actions Workflow:**

**Triggers:**
- Push to main branch
- Pull requests to main

**Jobs:**
1. Install dependencies (`npm ci`)
2. Run linting (`npm run lint`)
3. Run type checking (`npx tsc --noEmit`)
4. Run tests (`npm test`)
5. Generate coverage report
6. Build project (`npm run build`)
7. Validate build artifacts exist

**Matrix Testing:** Node.js 18.x, 20.x, 22.x

**Performance Target:** <5 minutes execution time

### Testing

**Test Framework:** Vitest 1.2.2

**Test File Location:**
- Unit tests: `tests/unit/[component]/`
- Integration tests: `tests/integration/` (future)

**Test Standards:**
- Follow AAA pattern (Arrange, Act, Assert)
- Mock all external dependencies
- Use descriptive test names

**Coverage Requirements:**
- Core infrastructure (src/client/): ≥90%
- API modules (src/modules/): ≥80%
- Critical paths: 100%

**Initial Test:**
Create `tests/unit/index.test.ts` to validate version export function:
```typescript
import { describe, it, expect } from 'vitest';
import { version } from '../../src/index';

describe('SDK Index', () => {
  it('should export version string', () => {
    expect(version).toBeDefined();
    expect(typeof version).toBe('string');
    expect(version).toMatch(/^\d+\.\d+\.\d+$/);
  });
});
```
