# Story 2.7: Orders FBW Module - Wildberries Warehouse Integration

---

## Status

**Done**

---

## Story

**As a** marketplace seller using FBW (Fulfillment by Wildberries),
**I want** to manage orders fulfilled from Wildberries warehouses,
**so that** I can leverage Wildberries logistics infrastructure.

---

## Acceptance Criteria

1. Orders FBW module generated from `07-orders-fbw.yaml` with type definitions
2. `getWarehouses()` method retrieves list of Wildberries warehouses
3. `getAcceptanceCoefficients(warehouseIDs?: string)` method retrieves acceptance coefficients for next 14 days
4. `getAcceptanceOptions(goods: Good[], warehouseID?: string)` method retrieves available warehouses and package types for goods
5. `getTransitTariffs()` method retrieves transit directions and pricing
6. `getSupplies(filters: SupplyFilters, limit?, offset?)` method retrieves list of supplies with filters and pagination
7. `getSupplyDetails(id: number, isPreorderID?: boolean)` method retrieves single supply details
8. `getSupplyGoods(id: number, isPreorderID?, limit?, offset?)` method retrieves goods in supply with pagination
9. `getSupplyPackage(supplyId: number)` method retrieves package/box information
10. FBW-specific types differentiate from FBS types where applicable
11. Rate limits enforced per endpoint (two tiers: planning 6 req/min, supply info 30 req/min)
12. Unit tests validate all FBW module methods with ≥80% coverage
13. Integration tests validate complete FBW supply workflow with MSW
14. Example code demonstrates end-to-end FBW workflow (warehouse selection → coefficients → options → supply retrieval → goods/package info)

    ```typescript
    // Validate pagination
    if (limit < 1 || limit > 1000) {
      throw new ValidationError('Limit must be 1-1000');
    }
    if (offset < 0) {
      throw new ValidationError('Offset must be >= 0');
    }

    // Validate filters
    if (filters.dates) {
      filters.dates.forEach((dateFilter, idx) => {
        if (!dateFilter.type) {
          throw new ValidationError(`Date filter at index ${idx} missing type`);
        }
        if (!['factDate', 'createDate', 'supplyDate', 'updatedDate'].includes(dateFilter.type)) {
          throw new ValidationError(`Date filter type must be: factDate, createDate, supplyDate, or updatedDate`);
        }
        // Validate ISO date format
        if (dateFilter.from && !isValidISODate(dateFilter.from)) {
          throw new ValidationError(`Invalid from date format at index ${idx}. Use ISO 8601: YYYY-MM-DD`);
        }
        if (dateFilter.till && !isValidISODate(dateFilter.till)) {
          throw new ValidationError(`Invalid till date format at index ${idx}. Use ISO 8601: YYYY-MM-DD`);
        }
      });
    }

    if (filters.statusIDs) {
      const validStatuses = [1, 2, 3, 4, 5, 6];
      filters.statusIDs.forEach((status, idx) => {
        if (!validStatuses.includes(status)) {
          throw new ValidationError(`Invalid status ID at index ${idx}. Must be 1-6`);
        }
      });
    }

    const params = new URLSearchParams();
    params.append('limit', limit.toString());
    params.append('offset', offset.toString());

    return this.client.post<Supply[]>(
      `https://supplies-api.wildberries.ru/api/v1/supplies?${params.toString()}`,
      filters,
      { rateLimitKey: 'ordersFBW.getSupplies' }
    );
    ```
  - [ ] Add helper function:

    ```typescript
    function isValidISODate(dateStr: string): boolean {
      const isoRegex = /^\d{4}-\d{2}-\d{2}$/;
      if (!isoRegex.test(dateStr)) return false;
      const date = new Date(dateStr);
      return date instanceof Date && !isNaN(date.getTime());
    }
    ```

    ```typescript
    import { WildberriesSDK } from '../src';

    async function fbwWorkflowExample() {
      const sdk = new WildberriesSDK({
        apiKey: process.env.WB_API_KEY!
      });

      console.log('=== FBW Warehouse Supply Workflow ===\n');

      // 1. Get available warehouses
      console.log('1. Getting WB warehouses...');
      const warehouses = await sdk.ordersFBW.getWarehouses();
      console.log(`Found ${warehouses.length} warehouses`);
      const activeWarehouses = warehouses.filter(w => w.isActive);
      console.log(`Active: ${activeWarehouses.length}`);
      console.log(`Example: ${activeWarehouses[0].name} (${activeWarehouses[0].address})`);

      // 2. Check acceptance coefficients
      console.log('\n2. Checking acceptance coefficients for next 14 days...');
      const warehouseID = activeWarehouses[0].ID.toString();
      const coefficients = await sdk.ordersFBW.getAcceptanceCoefficients(warehouseID);
      const available = coefficients.filter(c =>
        (c.coefficient === 0 || c.coefficient === 1) && c.allowUnload
      );
      console.log(`Available dates: ${available.length}`);
      console.log(`First available: ${available[0].date} (coefficient: ${available[0].coefficient})`);

      // 3. Check acceptance options for products
      console.log('\n3. Checking acceptance options for products...');
      const goods = [
        { barcode: '1234567891234', quantity: 10 },
        { barcode: '9876543210987', quantity: 5 }
      ];
      const options = await sdk.ordersFBW.getAcceptanceOptions(goods, warehouseID);
      options.result.forEach(opt => {
        if (opt.isError) {
          console.log(`❌ ${opt.barcode}: ${opt.error.detail}`);
        } else {
          console.log(`✅ ${opt.barcode}: ${opt.warehouses.length} warehouses available`);
          if (opt.warehouses[0]) {
            console.log(`   Packages: Box=${opt.warehouses[0].canBox}, Monopallet=${opt.warehouses[0].canMonopallet}, Supersafe=${opt.warehouses[0].canSupersafe}`);
          }
        }
      });

      // 4. Get recent supplies
      console.log('\n4. Getting recent supplies...');
      const supplies = await sdk.ordersFBW.getSupplies({
        dates: [{
          from: '2024-01-01',
          till: '2024-12-31',
          type: 'createDate'
        }],
        statusIDs: [2, 3, 4, 5] // Planned, AllowUnload, Accepting, Accepted
      }, 10, 0);
      console.log(`Found ${supplies.length} supplies`);

      if (supplies.length > 0) {
        const supply = supplies[0];
        console.log(`Latest: Supply ${supply.supplyID} / Preorder ${supply.preorderID}`);
        console.log(`Status: ${supply.statusName} (ID: ${supply.statusID})`);
        console.log(`Created: ${supply.createDate}`);

        // 5. Get supply details
        if (supply.supplyID) {
          console.log('\n5. Getting supply details...');
          const details = await sdk.ordersFBW.getSupplyDetails(supply.supplyID);
          console.log(`Warehouse: ${details.warehouseName} (ID: ${details.warehouseID})`);
          console.log(`Box Type: ${details.boxTypeName} (ID: ${details.boxTypeID})`);
          console.log(`Quantities: added=${details.quantity}, accepted=${details.acceptedQuantity}, ready=${details.readyForSaleQuantity}`);
          console.log(`Acceptance Cost: ${details.acceptanceCost}₽`);

          // 6. Get goods in supply
          console.log('\n6. Getting goods in supply...');
          const supplyGoods = await sdk.ordersFBW.getSupplyGoods(supply.supplyID);
          console.log(`Found ${supplyGoods.length} products in supply`);
          supplyGoods.slice(0, 3).forEach(good => {
            console.log(`  - ${good.vendorCode}: ${good.quantity} units (barcode: ${good.barcode})`);
            console.log(`    Accepted: ${good.acceptedQuantity}, Ready: ${good.readyForSaleQuantity}`);
            if (good.needKiz) {
              console.log(`    ⚠️  Requires KIZ marking (TNVED: ${good.tnved || 'not set'})`);
            }
          });

          // 7. Get package info
          console.log('\n7. Getting package information...');
          const boxes = await sdk.ordersFBW.getSupplyPackage(supply.supplyID);
          console.log(`Found ${boxes.length} boxes/packages`);
          boxes.slice(0, 2).forEach(box => {
            console.log(`  Package ${box.packageCode}: ${box.quantity} total items`);
            console.log(`  Contains ${box.barcodes.length} different products`);
          });
        }
      }

      // 8. Check transit tariffs
      console.log('\n8. Getting transit tariffs...');
      const tariffs = await sdk.ordersFBW.getTransitTariffs();
      console.log(`Found ${tariffs.length} transit routes`);
      tariffs.slice(0, 3).forEach(tariff => {
        console.log(`  ${tariff.transitWarehouseName} → ${tariff.destinationWarehouseName}`);
    ```

### Data Models

**Supply Statuses (statusID):** [Source: wildberries_api_doc/07-orders-fbw.yaml:594-605, 916-931]
- `1` - Not Planned (Не запланировано)
- `2` - Planned (Запланировано)
- `3` - Unload Allowed (Отгрузка разрешена)
- `4` - Accepting (Идёт приёмка)
- `5` - Accepted (Принято)
- `6` - Unloaded on Gate (Отгружено на воротах)

**Box Types (boxTypeID):** [Source: wildberries_api_doc/07-orders-fbw.yaml:749-756]
- `0` - No Boxes (virtual supply)
- `1` and `2` - Boxes (Короба)
- `5` - Monopallets (Монопаллеты)
- `6` - Supersafe (Суперсейф)

**Virtual Supply Types (virtualTypeID):** [Source: wildberries_api_doc/07-orders-fbw.yaml:730-738]
- `0` - Stock Transfer (Перенос остатков)
- `1` - Depersonalization (Обезличка)
- `4` - QR Supply (QR-поставка)
- `5` - Additional Acceptance (Допринято)
- `6` - Scan Acceptance (Скан-приёмка)

**Date Filter Types:** [Source: wildberries_api_doc/07-orders-fbw.yaml:682-692]
- `factDate` - Actual ship date
- `createDate` - Creation date
- `supplyDate` - Planned ship date
- `updatedDate` - Last update date

**Acceptance Rules:** [Source: wildberries_api_doc/07-orders-fbw.yaml:34-36]
- Acceptance available ONLY when: `coefficient` = 0 or 1 AND `allowUnload` = true
- `coefficient` = -1 means acceptance unavailable regardless of allowUnload
- `coefficient` = 0 means free acceptance
- `coefficient` ≥ 1 means paid acceptance (multiplier)

**KIZ (Marking) Requirements:** [Source: wildberries_api_doc/07-orders-fbw.yaml:618-629]
- If `needKiz` = true, product requires честныйзнак.рф marking code
- TNVED field must be populated (either in product card or via API)
- If needKiz=true and tnved=null, update product characteristic

**Validation Constraints:**
- Goods array: max 5000 items [Source: wildberries_api_doc/07-orders-fbw.yaml:112]
- Good quantity: 1-999999 per item [Source: wildberries_api_doc/07-orders-fbw.yaml:1072-1074]
- Warehouse ID param: max 1 value when filtering [Source: wildberries_api_doc/07-orders-fbw.yaml:103]
- Supply list limit: 1-1000 (default 1000) [Source: wildberries_api_doc/07-orders-fbw.yaml:237-240]
- Supply goods limit: 1-1000 (default 100) [Source: wildberries_api_doc/07-orders-fbw.yaml:409-412]
- Date format: ISO 8601 (YYYY-MM-DD) [Source: wildberries_api_doc/07-orders-fbw.yaml:673-679]
