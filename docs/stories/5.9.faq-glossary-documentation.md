## Getting Started

### How do I install the SDK?

Install via npm:

\`\`\`bash
npm install wb-api-sdk
\`\`\`

**See:** [Installation Guide](getting-started/installation.md)

### Where do I get an API key?

1. Log in to [Wildberries Seller Dashboard](https://seller.wildberries.ru/)
2. Navigate to Settings → API Access
3. Generate new API key
4. Copy and save securely (shown only once)

**See:** [Authentication Guide](guides/authentication.md)

### What Node.js version is required?

Node.js ≥ 20.0.0 is required.

**See:** [System Requirements](getting-started/installation.md#requirements)

---

## API Usage

### How do I handle rate limits?

The SDK automatically handles rate limits with exponential backoff. No action needed from your side.

**See:** [Rate Limiting Guide](guides/best-practices.md#rate-limiting)

### Can I use the SDK in a browser?

No, the SDK is designed for Node.js server-side applications only. Browser usage is not supported due to security concerns (API key exposure).

### How do I update multiple products at once?

Use batch operations:

\`\`\`typescript
const updates = [...]; // Array of product updates
await sdk.products.updateBatch(updates);
\`\`\`

**See:** [Batch Operations Example](examples/batch-operations.ts)

---

## Troubleshooting

### Why am I getting "Authentication failed"?

**Common causes:**
1. API key not set in environment variable
2. Invalid or expired API key
3. Extra whitespace in API key

**Solution:** Verify your API key:
\`\`\`bash
echo $WB_API_KEY  # Should show your key
\`\`\`

**See:** [Authentication Troubleshooting](guides/troubleshooting.md#authentication)

### How do I enable debug logging?

\`\`\`typescript
const sdk = new WildberriesSDK({
  apiKey: process.env.WB_API_KEY!,
  logLevel: 'debug'
});
\`\`\`

**See:** [Debug Mode](guides/troubleshooting.md#debug-mode)

## Billing & Limits

### What are the API rate limits?

Rate limits vary by endpoint. Common limits:
- Products: 1 request/10 seconds
- Orders: 3 requests/minute
- Analytics: 5 requests/minute

**See:** [Rate Limits Reference](api/rate-limits.md)

### Is there a free tier?

Yes, the API has a free tier with standard rate limits. Contact Wildberries for enterprise pricing.

**See:** [Pricing Information](https://seller.wildberries.ru/pricing)

### Glossary Structure

```markdown
# Glossary

Definitions of Wildberries and SDK terminology.

## Wildberries Terms

### FBS (Fulfillment by Seller)
Order fulfillment model where the seller stores, packs, and ships products directly to customers.

**See also:** FBW, Orders FBS Module

### FBW (Fulfillment by Wildberries)
Order fulfillment model where Wildberries stores, packs, and ships products on behalf of the seller.

**See also:** FBS, Orders FBW Module

### SKU (Stock Keeping Unit)
Unique identifier for each distinct product or variant in inventory.

**Example:** ELEC-TV-55-4K-001

### Barcode
Product identifier used for tracking inventory and sales. Wildberries uses EAN-13 and Code 128 formats.

**See:** [Barcode Guide](guides/barcodes.md)

---

## SDK Terms

### Module
A logical grouping of related API methods in the SDK.

**Example:** Products Module, Orders Module, Finances Module

**See:** [SDK Architecture](../architecture.md#modules)

### Base Client
Core HTTP client handling authentication, rate limiting, and retries for all modules.

**See:** [Base Client Documentation](api/classes/BaseClient.html)

### Rate Limiter
Component that enforces per-endpoint rate limits to prevent API quota exhaustion.

**See:** [Rate Limiting](guides/best-practices.md#rate-limiting)

---

## API Concepts

### Rate Limiting
Restriction on the number of API requests allowed within a time period to ensure fair usage.

**See:** [Rate Limits Reference](api/rate-limits.md)

### Pagination
Technique for splitting large result sets into smaller "pages" to improve performance.

**Example:**
\`\`\`typescript
const page1 = await sdk.products.list({ page: 1, limit: 100 });
const page2 = await sdk.products.list({ page: 2, limit: 100 });
\`\`\`

### Idempotency
Property of an operation where performing it multiple times has the same effect as performing it once.

**Example:** Creating a product with same ID twice returns existing product

### Authentication
Process of verifying identity using an API key before accessing protected resources.

**See:** [Authentication Guide](guides/authentication.md)

```
