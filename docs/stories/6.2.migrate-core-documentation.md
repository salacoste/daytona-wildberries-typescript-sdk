### VitePress Frontmatter Requirements

**Frontmatter template for all pages:**
```yaml
---
title: Page Title               # Browser tab title (required)
description: SEO description    # Meta description, max 160 chars (required)
layout: doc                     # Layout type: doc (default), home, or page
sidebar: true                   # Show sidebar (default: true)
prev:                           # Previous page link (optional)
  text: 'Previous Page'
  link: '/path/to/prev'
next:                           # Next page link (optional)
  text: 'Next Page'
  link: '/path/to/next'
---
```

**Best Practices:**
- Title: Match h1 heading in content
- Description: Concise, actionable, includes primary keywords
- Layout: Use "doc" for standard documentation pages
- Prev/Next: Configure for tutorial sequences, optional elsewhere

[Source: Context7 VitePress docs + docs/EPIC_6_PRD.md#4.3-coding-standards]

### Internal Link Conversion

**Markdown Links → VitePress Router Links:**

**Before (relative markdown):**
```markdown
See [Installation Guide](./installation.md) for details.
See [FAQ](../FAQ.md) for common questions.
```

**After (VitePress router links):**
```markdown
See [Installation Guide](/getting-started/installation) for details.
See [FAQ](/FAQ) for common questions.
```

**Conversion Rules:**
1. Remove `.md` extensions
2. Convert relative paths (`./`, `../`) to absolute paths from docs root
3. Use lowercase kebab-case for URLs
4. Test all links work in VitePress dev server

[Source: Context7 VitePress docs + docs/EPIC_6_PRD.md#cr4-markdown-content-compatibility]

### Code Block Standards

**Language identifiers required:**
```markdown
# Bad (no syntax highlighting)
```
npm install daytona-wildberries-typescript-sdk
```

# Good (syntax highlighting)
```bash
npm install daytona-wildberries-typescript-sdk
```

# TypeScript examples
```typescript
import { WildberriesSDK } from 'daytona-wildberries-typescript-sdk';
const sdk = new WildberriesSDK({ apiKey: 'your-api-key' });
```

# JSON examples
```json
{
  "apiKey": "your-api-key",
  "timeout": 30000
}
```
```

**Common language identifiers:**
- `typescript` - TypeScript code
- `bash` - Shell commands
- `json` - JSON configuration
- `yaml` - YAML configuration
- `javascript` - JavaScript code
- `markdown` - Markdown examples
