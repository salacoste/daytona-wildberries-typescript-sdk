## Context

### Background

The Communications module is a HIGH priority business module enabling sellers to manage all customer interactions on the Wildberries platform. This includes responding to product questions, managing customer reviews/feedbacks, using response templates for efficiency, handling live chat conversations, and managing return claims. Effective communication is critical for seller ratings and customer satisfaction.

**Key Communication Operations**:
- **Questions Management**: View, respond to, and track customer questions about products
- **Feedbacks/Reviews Management**: Monitor, respond to, and manage customer reviews and ratings
- **Response Templates**: Create and manage reusable response templates for common questions
- **Customer Chat**: Real-time chat conversations with customers
- **Claims/Returns Management**: Handle customer return claims and requests
