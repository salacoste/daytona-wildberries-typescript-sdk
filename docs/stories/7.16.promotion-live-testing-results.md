## Bug Fixed

### getStatsKeywords URL Error

**Issue**: SSL certificate error when calling `getStatsKeywords()`

**Error Message**:
```
ERR_TLS_CERT_ALTNAME_INVALID: Host: api.wildberries.ru
```

**Root Cause**: Incorrect base URL in `src/modules/promotion/index.ts:712`

**Fix Applied**:
```typescript
// Before (line 712):
return this.client.get<V0KeywordsStatisticsResponse>(
  'https://api.wildberries.ru/adv/v0/stats/keywords',
  { params: options }
);

// After (fixed):
return this.client.get<V0KeywordsStatisticsResponse>(
  'https://advert-api.wildberries.ru/adv/v0/stats/keywords',
  { params: options }
);
```

**Verification**: Method now works correctly with active campaigns.

## Discovered SDK Method Names

The SDK uses generated method names from Swagger. The correct names are:

### Campaign Control Methods

| Operation | SDK Method Name | HTTP | Endpoint |
|-----------|-----------------|------|----------|
| Start campaign | `getAdvStart()` | GET | `/adv/v0/start` |
| Pause campaign | `getAdvPause()` | GET | `/adv/v0/pause` |
| Stop campaign | `getAdvStop()` | GET | `/adv/v0/stop` |
| Delete campaign | `getAdvDelete()` | GET | `/adv/v0/delete` |
| Rename campaign | `createAdvRename()` | POST | `/adv/v0/rename` |

### Bid Management Methods

| Operation | SDK Method Name | HTTP | Endpoint |
|-----------|-----------------|------|----------|
| Min bids | `createBidsMin()` | POST | `/adv/v0/bids/min` |
| Update unified bid | `updateAdvBid()` | PATCH | `/adv/v0/bids` |
| Update manual bid | `updateAuctionBid()` | PATCH | `/adv/v0/auction/bids` |

## API Requirements Discovered

### Campaign Status Requirements

| Method | Required Status | Description |
|--------|-----------------|-------------|
| `getAdvStart()` | 4 or 11 | Ready or Paused |
| `getAdvPause()` | 9 | Active only |
| `getAdvStop()` | 4, 9, or 11 | Ready, Active, or Paused |
| `getAdvDelete()` | 4 | Ready only |
| `createBudgetDeposit()` | 11 (per docs) | Paused; but tested working for status 4 |
| `createSearchSetExcluded()` | 9 | Active only |
| `getSearchSetPlus()` | 9 | Active only |

### Parameter Requirements

| Method | Required Parameters |
|--------|---------------------|
| `createBidsMin()` | `advert_id`, `nm_ids[]`, `payment_type`, `placement_types[]` |
| `updateAuctionBid()` | `bids[].advert_id`, `bids[].nm_bids[].nm_id`, `bids[].nm_bids[].bid`, `bids[].nm_bids[].placement` |
| `createSearchSetPlu()` | `pluse[]` (phrases must exist in campaign's keyword list) |

## Campaign Lifecycle Confirmed

```
Status Codes:
  -1 = Deleting (3-10 minutes)
   4 = Ready
   7 = Finished
   8 = Cancelled
   9 = Active
  11 = Paused

Campaign Types:
   8 = Unified bid (deprecated)
   9 = Unified or Manual bid (current)

Bid Types:
   manual   = Manual bid per placement
   unified  = Single bid for all placements
```

## Recommendations

### For SDK Users

1. **Use correct method names** - Generated from Swagger (e.g., `getAdvStart()` not `startAdvert()`)
2. **Respect status requirements** - Check campaign status before operations
3. **Implement delays** - 5 seconds between most calls
4. **Handle errors** - Use try/catch with typed errors

### For SDK Development

1. **Consider method aliases** - Add intuitive aliases like `startCampaign()` → `getAdvStart()`
2. **Add status validation** - Validate campaign status before state-changing operations
3. **Document requirements** - Include status requirements in JSDoc
