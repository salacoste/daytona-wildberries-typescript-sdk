## Context

### Background

B2B (Business-to-Business) orders on Wildberries come from corporate buyers - legal entities and individual entrepreneurs (IP). Unlike B2C orders from individual consumers, B2B orders require special handling for accounting and tax purposes:

**B2B vs B2C Orders:**
| Aspect | B2B Orders | B2C Orders |
| --- | --- | --- |
| Buyer | Legal entity or IP | Individual consumer |
| Documents | Invoice, waybill, act | Receipt only |
| Tax data | INN, KPP required | Not applicable |
| Accounting | Full accounting records | Simplified |

**B2B Data Components:**
- **orgName**: Official organization name (e.g., "IP Ivanov I.I.", "OOO Roga i Kopyta")
- **inn**: Tax Identification Number (INN) - always present, 10 digits for legal entities, 12 for IP
- **kpp**: Tax Registration Reason Code (KPP) - present for legal entities, empty for IP

**Business Use Cases:**
1. **Invoice Generation**: Create proper invoices with buyer's legal details
2. **Waybill Preparation**: Include organization data in shipping documents
3. **Tax Reporting**: Maintain records for tax compliance
4. **Counterparty Verification**: Validate buyer before shipment
5. **B2B vs B2C Detection**: Identify corporate orders (B2C returns 404)

### Technical Context

### Task 2: getB2BInfo() Method Implementation
**Acceptance Criteria**: 1, 2, 3, 4, 5, 6, 8

- [ ] Add method to OrdersDbsModule:
  ```typescript
  /**
   * Get B2B buyer information for corporate orders
   *
   * Returns organization data (INN, KPP, company name) for B2B orders.
   * Orders from individual consumers (B2C) will return 404 errors.
   *
   * Rate limit: 300 requests per minute, 200ms interval
   *
   * @param orderIds - Array of order IDs (1-1000)
   * @returns B2B buyer information with partial success support
   * @throws {ValidationError} When orderIds array is empty or exceeds 1000
   * @throws {AuthenticationError} When API key is invalid
   * @throws {RateLimitError} When rate limit exceeded
   *
   * @example
   * ```typescript
   * const result = await sdk.ordersDBS.getB2BInfo([4299281547, 4279781545]);
   *
   * for (const item of result.results) {
   *   if (!item.isError && item.data) {
   *     console.log(`Order ${item.orderId}: ${item.data.orgName} (INN: ${item.data.inn})`);
   *   } else {
   *     console.log(`Order ${item.orderId}: Not a B2B order`);
   *   }
   * }
   * ```
   */
  async getB2BInfo(orderIds: number[]): Promise<GetB2BInfoResponse> {
    // Input validation
    if (!orderIds || orderIds.length === 0) {
      throw new ValidationError('orderIds array cannot be empty');
    }
    if (orderIds.length > 1000) {
      throw new ValidationError('orderIds array cannot exceed 1000 items');
    }

    return this.client.post<GetB2BInfoResponse>(
      'https://marketplace-api.wildberries.ru/api/marketplace/v3/dbs/orders/b2b/info',
      { ordersIds: orderIds },
      { rateLimitKey: 'orders-dbs.getB2BInfo' }
    );
  }
  ```

  /**
   * Check if an order is a B2B order
   *
   * @param orderId - Single order ID to check
   * @returns True if order is B2B, false if B2C
   *
   * @example
   * ```typescript
   * const isB2B = await sdk.ordersDBS.isB2BOrder(4299281547);
   * if (isB2B) {
   *   // Process as B2B order
   * }
   * ```
   */
  async isB2BOrder(orderId: number): Promise<boolean> {
    const result = await this.getB2BInfo([orderId]);
    return result.results[0]?.isError === false;
  }
  ```
- [ ] Add helper to extract successful B2B data only:
  ```typescript
  /**
   * Get B2B data for orders, filtering out non-B2B orders
   *
   * @param orderIds - Array of order IDs
   * @returns Map of orderId to B2BData for B2B orders only
   */
  async getB2BDataOnly(orderIds: number[]): Promise<Map<number, B2BData>> {
    const result = await this.getB2BInfo(orderIds);
    const b2bMap = new Map<number, B2BData>();

    for (const item of result.results) {

        b2bMap.set(item.orderId, item.data);
      }
    }

    return b2bMap;
  }

  import { WildberriesSDK } from '../src';

  async function processB2BOrders() {
    const sdk = new WildberriesSDK({
      apiKey: process.env.WB_API_KEY || 'your-api-key'
    });

    console.log('=== DBS B2B Order Processing ===\n');

    try {
      // 1. Get new DBS orders
      console.log('1. Fetching new DBS orders...');
      const newOrders = await sdk.ordersDBS.getNewOrders();
      const orderIds = newOrders.orders.map(o => o.id);
      console.log(`   Found ${orderIds.length} new orders\n`);

      if (orderIds.length === 0) {
        console.log('   No orders to process');
        return;
      }

      // 2. Check which orders are B2B
      console.log('2. Checking B2B status...');
      const b2bInfo = await sdk.ordersDBS.getB2BInfo(orderIds);
      console.log(`   Request ID: ${b2bInfo.requestId}\n`);

      // 3. Separate B2B and B2C orders
      const b2bOrders: Array<{ orderId: number; data: { orgName: string; inn: string; kpp: string } }> = [];
      const b2cOrders: number[] = [];

      for (const result of b2bInfo.results) {
        if (!result.isError && result.data) {
          b2bOrders.push({ orderId: result.orderId, data: result.data });
        } else {
          b2cOrders.push(result.orderId);
        }
      }

      console.log('3. Order Classification:');
      console.log(`   B2B Orders: ${b2bOrders.length}`);
      console.log(`   B2C Orders: ${b2cOrders.length}\n`);

      // 4. Process B2B orders
      if (b2bOrders.length > 0) {
        console.log('4. B2B Order Details:');
        console.log('   ─────────────────────────────────────────');

        for (const order of b2bOrders) {
          const { orderId, data } = order;
          console.log(`   Order #${orderId}:`);
          console.log(`     Organization: ${data.orgName}`);
          console.log(`     INN: ${data.inn}`);
          console.log(`     KPP: ${data.kpp || '(empty - Individual Entrepreneur)'}`);
          console.log('');

          // Here you would generate invoice/waybill

        }
      }

      // 5. Summary
      console.log('5. Processing Summary:');
      console.log(`   Total orders processed: ${orderIds.length}`);
      console.log(`   B2B invoices to generate: ${b2bOrders.length}`);
      console.log(`   B2C receipts to generate: ${b2cOrders.length}`);

    } catch (error) {
      console.error('Error processing B2B orders:', error);
    }

### INN/KPP Format Reference

**INN (Tax Identification Number)**:
- Legal entities: 10 digits
- Individual entrepreneurs (IP): 12 digits

**KPP (Tax Registration Reason Code)**:
- Legal entities: 9 digits
- Individual entrepreneurs: Empty string (IP don't have KPP)

### Error Codes

| Code | Detail | Meaning |

| 400 | BadRequest | Invalid order ID format |
| 401 | Unauthorized | Invalid API key |
| 403 | Forbidden | Access denied |
| 429 | TooManyRequests | Rate limit exceeded |
