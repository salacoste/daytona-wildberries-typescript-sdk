### Module Architecture

**Time-Series Data Pattern**:
- All analytics methods return time-series data for trend analysis
- Time-series format: array of `{ date: string, value: number, metadata?: object }[]`
- Aggregation levels: daily, weekly, monthly (check OpenAPI spec for API support)
- Frontend can render charts directly from time-series structure

**Bulk Request Handling**:
- `getProductPerformance()` accepts array of product IDs
- API may have limits (e.g., max 50 products per request)
- For >50 products, implement batching in consumer code or provide helper method
- Document bulk limits clearly in JSDoc

**Metric Calculation Philosophy**:
- Some metrics calculated by API (revenue, units sold)
- Some metrics may need client-side calculation (conversion rates, percentages)
- Provide helper methods for common calculations
- Document which metrics are API-provided vs client-calculated

**Analytics Data Characteristics**:
- Data aggregation delays (e.g., previous day data available after midnight)
- Date range limitations (e.g., max 90 days per request)
- Data retention policies (e.g., detailed data for 12 months, aggregated for longer)
- Extract specifics from `11-analytics.yaml` during implementation

- Standard e-commerce funnel: Views → Add to Cart → Purchase
- Calculate drop-off rates at each stage
- Identify bottlenecks in conversion process

**Product Performance Comparison**:

- Identify best/worst performers

```typescript
// Unit test pattern
describe('AnalyticsModule', () => {
  const mockClient = {
    get: vi.fn(),
    post: vi.fn(),
  } as unknown as BaseClient;

  const analytics = new AnalyticsModule(mockClient);

  it('should fetch sales funnel', async () => {
    mockClient.get.mockResolvedValue({
      views: 10000,
      addToCarts: 1500,
      purchases: 450,
      conversionRate: 4.5,
      timeSeries: [
        { date: '2024-01-01', conversionRate: 4.2 },
        { date: '2024-01-02', conversionRate: 4.8 }
      ]
    });

    const result = await analytics.getSalesFunnel({
      from: '2024-01-01',
      to: '2024-01-31'
    });

    expect(result.conversionRate).toBe(4.5);
    expect(result.timeSeries).toHaveLength(2);
  });
});

// Integration test pattern with MSW
```
