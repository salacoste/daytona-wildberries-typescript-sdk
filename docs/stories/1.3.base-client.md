# Story 1.3: BaseClient HTTP Infrastructure with Axios

---

## Status

**Draft**

---

## Story

**As a** SDK module developer,
**I want** a reusable HTTP client with authentication and error handling,
**so that** I can focus on implementing API methods without duplicating infrastructure code.

---

## Acceptance Criteria

1. `BaseClient` class created with Axios as HTTP client dependency
2. Constructor accepts `SDKConfig` interface with `apiKey`, `timeout`, optional `baseUrls` override
3. API key automatically injected as `Authorization: Bearer <key>` header on all requests
4. Supports GET, POST, PUT, PATCH, DELETE methods with generic TypeScript return types
5. Configurable timeout (default 30000ms) applied to all requests
6. HTTP errors automatically transformed to typed error classes (401→AuthenticationError, 429→RateLimitError, etc.)
7. Request/response logging support via optional debug mode
8. Unit tests with mocked Axios validate all HTTP methods and error transformations
9. Integration tests with MSW validate real request/response flows

### Authentication Implementation

private setupRequestInterceptor(): void {
  this.axios.interceptors.request.use((config) => {
    // Inject authentication header
    config.headers.Authorization = `Bearer ${this.apiKey}`;

    // Debug logging (sanitized)
    if (this.logLevel === 'debug') {
      this.log('debug', 'HTTP Request', {
        method: config.method?.toUpperCase(),
        url: config.url,
        headers: { ...config.headers, Authorization: 'Bearer ***' } // Sanitized

    }

    return config;
  });
}

### Error Transformation Logic

**Mapping Table:**

| HTTP Status | Axios Error Property | SDK Error Class | Special Properties |
|-------------|---------------------|-----------------|-------------------|
| 401, 403 | error.response.status | AuthenticationError | statusCode |
| 429 | error.response.status | RateLimitError | retryAfter (from Retry-After header) |
| 400, 422 | error.response.status | ValidationError | fieldErrors (from response body) |
| 500-599 | error.response.status | NetworkError | statusCode, cause, isTimeout=false |
| ECONNABORTED | error.code | NetworkError | statusCode=0, cause, isTimeout=true |
| ETIMEDOUT | error.code | NetworkError | statusCode=0, cause, isTimeout=true |
| No response | !error.response | NetworkError | statusCode=0, cause, isTimeout=false |

**Error Transformation Implementation:**
```typescript
private transformError(error: unknown): never {
  // Type guard for Axios error
  if (!axios.isAxiosError(error)) {
    throw new NetworkError('Unknown error occurred', 0, error as Error);
  }

  const axiosError = error;

  // No response = network failure
  if (!axiosError.response) {
    const isTimeout = axiosError.code === 'ECONNABORTED' || axiosError.code === 'ETIMEDOUT';
    throw new NetworkError(
      isTimeout ? 'Request timed out' : 'Network error occurred',
      0,
      axiosError,
      isTimeout
    );
  }

  const status = axiosError.response.status;
  const responseData = axiosError.response.data;

  // Transform based on status code
  if (status === 401 || status === 403) {
    throw new AuthenticationError(
      'Authentication failed. Please verify your API key.',
      status
    );
  }

  if (status === 429) {
    const retryAfter = this.parseRetryAfter(axiosError.response.headers['retry-after']);
    throw new RateLimitError(
      `Rate limit exceeded. Retry after ${retryAfter}ms`,
      retryAfter
    );
  }

  if (status === 400 || status === 422) {
    const fieldErrors = this.extractFieldErrors(responseData);
    throw new ValidationError(
      'Validation failed',
      status,
      fieldErrors
    );
  }

  if (status >= 500) {
    throw new NetworkError(
      `Server error: ${status}`,
      status,
      axiosError
    );
  }

  // Fallback for unexpected status codes
  throw new WBAPIError(`HTTP error ${status}`, status, responseData);
}
```

**Helper Methods:**
```typescript
private parseRetryAfter(header?: string): number {
  if (!header) return 5000; // Default 5 seconds
  const seconds = parseInt(header, 10);
  return isNaN(seconds) ? 5000 : seconds * 1000; // Convert to milliseconds
}

private extractFieldErrors(responseData: any): Record<string, string> | undefined {
  // Parse API-specific error format
  if (responseData?.errors && typeof responseData.errors === 'object') {
    return responseData.errors;
  }
  return undefined;
}
```

### Timeout Configuration

**Default:** 30 seconds (30000ms)

**Rationale:**
- Wildberries API can be slow for complex operations
- Prevents indefinite hanging
- Allows time for report generation endpoints

**Configuration:**
```typescript
const config: SDKConfig = {
  apiKey: 'key',
  timeout: 60000 // 60 seconds for report generation
};
```

**Timeout Error Handling:**
- Axios throws error with code 'ECONNABORTED' or 'ETIMEDOUT'
- Transformed to NetworkError with isTimeout=true
- RetryHandler (Story 1.5) will retry timeout errors

### Debug Logging Implementation

**Log Levels:** debug, info, warn, error

**Default:** warn (production), debug (development via config)

**Implementation:**
```typescript
private log(level: 'debug' | 'info' | 'warn' | 'error', message: string, meta?: unknown): void {
  const levels = { debug: 0, info: 1, warn: 2, error: 3 };
  const currentLevel = levels[this.logLevel];
  const messageLevel = levels[level];

  if (messageLevel < currentLevel) return; // Skip if below threshold

  const logData = {
    timestamp: new Date().toISOString(),
    level,
    service: 'WildberriesSDK',
    message,
    meta: this.sanitizeMeta(meta)
  };

  const consoleMethods = {
    debug: console.debug,
    info: console.info,
    warn: console.warn,
    error: console.error
  };

  consoleMethods[level](JSON.stringify(logData));
}

private sanitizeMeta(meta: unknown): unknown {
  if (!meta) return undefined;

  // Remove sensitive fields
  const sanitized = JSON.parse(JSON.stringify(meta));
  if (sanitized.headers?.Authorization) {
    sanitized.headers.Authorization = 'Bearer ***';
  }
  // Add more sanitization as needed

  return sanitized;
}
```

- ✅ Log: HTTP method, URL, status code, error messages
- ❌ NEVER log: Full API keys, tokens, PII, request/response bodies with sensitive data

```typescript
import { describe, it, expect, beforeEach } from 'vitest';
import MockAdapter from 'axios-mock-adapter';
import axios from 'axios';
import { BaseClient } from '../../../src/client/base-client';
import { AuthenticationError, RateLimitError } from '../../../src/errors';

describe('BaseClient', () => {
  let client: BaseClient;
  let mockAxios: MockAdapter;

  beforeEach(() => {
    mockAxios = new MockAdapter(axios);
    client = new BaseClient({ apiKey: 'test-key' });
  });

  it('should inject Authorization header', async () => {
    mockAxios.onGet('/test').reply((config) => {
      expect(config.headers?.Authorization).toBe('Bearer test-key');
      return [200, { data: 'success' }];
    });

    await client.get('/test');
  });

  it('should transform 401 to AuthenticationError', async () => {
    mockAxios.onGet('/test').reply(401, { error: 'Unauthorized' });

    await expect(client.get('/test')).rejects.toThrow(AuthenticationError);
  });

  it('should transform 429 to RateLimitError with retryAfter', async () => {
    mockAxios.onGet('/test').reply(429, { error: 'Rate limit' }, { 'retry-after': '10' });

    try {
      await client.get('/test');
    } catch (error) {
      expect(error).toBeInstanceOf(RateLimitError);
      expect((error as RateLimitError).retryAfter).toBe(10000); // 10 seconds in ms
    }
  });
});
```
