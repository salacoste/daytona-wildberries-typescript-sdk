## User Story

**As a** пользователь SDK,
**I want** рассчитать прогнозируемую стоимость поставки,
**so that** я могу выбрать оптимальный склад и дату для минимизации затрат.

---

## Business Context

Стоимость поставки складывается из:
- **Приёмка**: coefficient × базовая ставка по типу упаковки
- **Хранение**: (storageBaseLiter + (volume-1) × storageAdditionalLiter) × storageCoef/100 × дни
- **Логистика**: (deliveryBaseLiter + (volume-1) × deliveryAdditionalLiter) × deliveryCoef/100

Продавцу важно сравнить затраты по разным складам и датам для выбора оптимального варианта.

## Technical Specification

### Input Interface

```typescript
interface SupplyCostInput {
  volume: number;            // Объём товара в литрах
  warehouseID: number;       // ID склада
  days: number;              // Планируемый срок хранения
  boxType?: 'box' | 'pallet' | 'supersafe';  // Тип упаковки
  coefficientsData: ModelsAcceptanceCoefficient;  // Данные коэффициентов
}
```

### Output Interface

```typescript
interface SupplyCostResult {
  acceptanceCost: number;     // Стоимость приёмки, ₽
  storageCost: number;        // Стоимость хранения, ₽
  logisticsCost: number;      // Стоимость логистики, ₽
  totalCost: number;          // Общая стоимость, ₽
  warehouseName: string;      // Название склада
  appliedCoefficients: {
    acceptance: number;       // Коэффициент приёмки
    storage: number;          // Коэффициент хранения (%)
    delivery: number;         // Коэффициент логистики (%)
  };
}
```

## Calculation Formulas

### Storage Cost

```
storageCost = (storageBaseLiter + (volume - 1) × storageAdditionalLiter)
              × (storageCoef / 100)
              × days
```

### Logistics Cost

```
logisticsCost = (deliveryBaseLiter + (volume - 1) × deliveryAdditionalLiter)
                × (deliveryCoef / 100)
```

### Acceptance Cost

```
acceptanceCost = coefficient × baseAcceptanceRate[boxType]
```

Базовые ставки приёмки (примерные):
- Короба: 50 ₽
- Монопаллеты: 500 ₽
- Суперсейф: 100 ₽

### Total Cost

```
totalCost = acceptanceCost + storageCost + logisticsCost
```

## Example Usage

```typescript
import { calculateSupplyCost, compareSupplyCosts } from 'wb-api-sdk';

// 1. Расчёт для одного склада
const krasnodarCost = calculateSupplyCost({
  volume: 10,
  warehouseID: 218623,
  days: 30,
  boxType: 'box',
  coefficientsData: {
    coefficient: 1,
    storageCoef: '165',
    deliveryCoef: '165',
    storageBaseLiter: '0.13',
    storageAdditionalLiter: '0.13',
    deliveryBaseLiter: '75.9',
    deliveryAdditionalLiter: '23.1',
    warehouseName: 'Краснодар (Тихорецкая)'
  }
});

console.log(`
Склад: ${krasnodarCost.warehouseName}
Приёмка: ${krasnodarCost.acceptanceCost} ₽
Хранение (30 дней): ${krasnodarCost.storageCost} ₽
Логистика: ${krasnodarCost.logisticsCost} ₽
ИТОГО: ${krasnodarCost.totalCost} ₽
`);

// 2. Сравнение нескольких складов
const comparison = compareSupplyCosts([
  { warehouseID: 218623, coefficientsData: krasnodarCoefs },
  { warehouseID: 507, coefficientsData: koledinoCoefs },
], { volume: 10, days: 30 });

console.log('Рейтинг складов по стоимости:');
comparison.forEach((result, i) => {
  console.log(`${i+1}. ${result.warehouseName}: ${result.totalCost} ₽`);
});
```
