## User Story

**As a** пользователь SDK,
**I want** сравнить тарифы на остаток и поставку для выбора оптимальной стратегии,
**so that** я могу принять решение: отправлять товар на склад WB или хранить на своём складе.

---

## Business Context

Продавец выбирает между двумя стратегиями:
1. **FBW (склад WB)**: тарифы из `/api/v1/acceptance/coefficients` — коэффициенты на поставку
2. **FBS (остаток)**: тарифы из `/api/v1/tariffs/box` — тарифы на остаток

### Два типа тарифов

| API | Тип | URL | Описание |
|-----|-----|-----|----------|
| tariffs/box | Тарифы на остаток | common-api.wildberries.ru | Для товаров уже на складе WB |
| acceptance/coefficients | Тарифы на поставку | supplies-api.wildberries.ru | Для планирования новых поставок |

Сравнение помогает понять, что выгоднее: поставить товар на склад WB сейчас или подождать лучших условий.

## Technical Specification

### Input Interface

```typescript
interface CompareTariffsInput {
  warehouseName: string;  // Название склада для поиска
  date: string;           // Дата для сравнения (YYYY-MM-DD)
}
```

### Output Interface

```typescript
interface TariffComparison {
  warehouseName: string;
  date: string;
  inventory: {            // Тарифы на остаток (tariffs/box)
    deliveryBase: number;
    deliveryCoef: number;
    storageBase: number;
    storageCoef: number;
    found: boolean;
  };
  supply: {               // Тарифы на поставку (acceptance/coefficients)
    deliveryBase: number;
    deliveryCoef: number;
    storageBase: number;
    storageCoef: number;
    found: boolean;
  };
  difference: {
    deliveryBasePercent: number;  // % разница в базовой ставке логистики
    storageBasePercent: number;   // % разница в базовой ставке хранения
  };
  recommendation: 'SUPPLY_CHEAPER' | 'INVENTORY_CHEAPER' | 'EQUAL';
}
```

---

## Comparison Logic

### Percentage Difference Formula

```
deliveryBasePercent = ((supply.deliveryBase - inventory.deliveryBase) / inventory.deliveryBase) × 100
storageBasePercent = ((supply.storageBase - inventory.storageBase) / inventory.storageBase) × 100
```

### Recommendation Rules

```typescript
if (supply.deliveryBase < inventory.deliveryBase &&
    supply.storageBase <= inventory.storageBase) {
  return 'SUPPLY_CHEAPER';
}

if (inventory.deliveryBase < supply.deliveryBase &&
    inventory.storageBase <= supply.storageBase) {
  return 'INVENTORY_CHEAPER';
}

if (Math.abs(deliveryBasePercent) < 1 && Math.abs(storageBasePercent) < 1) {
  return 'EQUAL';
}

// Взвешенное сравнение для смешанных случаев
const inventoryScore = inventory.deliveryBase + inventory.storageBase * 30;
const supplyScore = supply.deliveryBase + supply.storageBase * 30;

return supplyScore < inventoryScore ? 'SUPPLY_CHEAPER' : 'INVENTORY_CHEAPER';
```

### Warehouse Name Matching

API могут возвращать разные названия складов:
- tariffs/box: `"Краснодар"`
- acceptance/coefficients: `"Краснодар (Тихорецкая)"`

Используем partial match:
```typescript
function matchWarehouse(name: string, target: string): boolean {
  return target.toLowerCase().includes(name.toLowerCase()) ||
         name.toLowerCase().includes(target.toLowerCase());
}
```

## Example Usage

```typescript
import { compareTariffs } from 'wb-api-sdk';

// Сравнить тарифы для Краснодара
const comparison = await compareTariffs(
  { warehouseName: 'Краснодар', date: '2025-01-25' },
  () => sdk.tariffs.getBoxStorageTariffs(),
  () => sdk.ordersFbw.getAcceptanceCoefficients()
);

console.log(`
Склад: ${comparison.warehouseName}
Дата: ${comparison.date}

📦 Тарифы на ОСТАТОК (FBS):
  Логистика: ${comparison.inventory.deliveryBase} ₽/л (coef: ${comparison.inventory.deliveryCoef}%)
  Хранение: ${comparison.inventory.storageBase} ₽/л/день (coef: ${comparison.inventory.storageCoef}%)

🚚 Тарифы на ПОСТАВКУ (FBW):
  Логистика: ${comparison.supply.deliveryBase} ₽/л (coef: ${comparison.supply.deliveryCoef}%)
  Хранение: ${comparison.supply.storageBase} ₽/л/день (coef: ${comparison.supply.storageCoef}%)

📊 Разница:
  Логистика: ${comparison.difference.deliveryBasePercent > 0 ? '+' : ''}${comparison.difference.deliveryBasePercent.toFixed(1)}%
  Хранение: ${comparison.difference.storageBasePercent > 0 ? '+' : ''}${comparison.difference.storageBasePercent.toFixed(1)}%

✅ Рекомендация: ${comparison.recommendation}
`);

// Пример вывода для Краснодара:
// Склад: Краснодар
// Тарифы на ОСТАТОК: 73.6 ₽/л, 0.10 ₽/л/день
// Тарифы на ПОСТАВКУ: 75.9 ₽/л, 0.13 ₽/л/день
// Разница: +3.1%, +30%
// Рекомендация: INVENTORY_CHEAPER
```
