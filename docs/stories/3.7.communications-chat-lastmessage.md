## Story

**As a** marketplace seller,
**I want** to see the last message in each chat conversation,
**so that** I can quickly identify which chats need attention without loading full message history.

---

## Context

On December 24, 2025, Wildberries API team announced an update to the Buyers Chat endpoint:

> "In the response of the Chat List method, we added the lastMessage object with information about the last message in the chat:
> - text — message text
> - addTimestamp — message time"

**API Reference:**
- EN: https://dev.wildberries.ru/en/openapi/user-communication#tag/Buyers-Chat/paths/~1api~1v1~1seller~1chats/get
- RU: https://dev.wildberries.ru/openapi/user-communication#tag/Chat-s-pokupatelyami/paths/~1api~1v1~1seller~1chats/get

**Business Value:**
- Reduces API calls needed to display chat previews
- Improves seller dashboard performance (no need to fetch events for preview)
- Better UX for chat list (shows message snippet and timestamp)
- Enables sorting chats by last activity time

## Technical Design

### API Changes

**Endpoint:** `GET /api/v1/seller/chats`
**Change:** Added optional `lastMessage` object to `Chat` schema

**New Schema:**
```yaml
LastMessage:
  type: object
  description: Информация о последнем сообщении в чате
  properties:
    text:
      type: string
      description: Текст сообщения
      example: Можно заказать 100 штук?
    addTimestamp:
      type: integer
      format: int64
      description: Время сообщения в формате Unix timestamp (миллисекунды)
      example: 1766138234889
```

**Updated Chat Schema:**
```yaml
Chat:
  properties:
    chatID: string
    replySign: string
    clientID: string
    clientName: string
    goodCard: GoodCard
    lastMessage: LastMessage  # NEW FIELD
```

### TypeScript Types

**File:** `src/types/communications.types.ts`

```typescript
/**
 * Информация о последнем сообщении в чате
 */
export interface LastMessage {
  /** Текст сообщения */
  text?: string;
  /** Время сообщения в формате Unix timestamp (миллисекунды) */
  addTimestamp?: number;
}

export interface Chat {
  chatID?: string;
  replySign?: string;
  clientID?: string;
  clientName?: string;
  goodCard?: GoodCard;
  lastMessage?: LastMessage;  // NEW FIELD
}
```

### Implementation Notes

**Timestamp Format:**
- Unix timestamp in **milliseconds** (not seconds)
- Example: `1766560630132` = December 24, 2025, 10:17:10 AM Moscow Time
- Convert to Date: `new Date(addTimestamp)`

**Field Availability:**
- Field is **optional** - not all chats may have it
- Testing showed 95.9% coverage (47 out of 49 chats had lastMessage)
- Chats without messages may not have this field

**Performance Impact:**
- No performance degradation
- Field is pre-computed by API (no additional queries)
- Reduces need for client-side event polling for chat previews

## Usage Examples

### Basic Usage

```typescript
import { WildberriesSDK } from 'daytona-wildberries-typescript-sdk';

const sdk = new WildberriesSDK({ apiKey: API_KEY });

// Get chat list
const chats = await sdk.communications.getSellerChats();

// Display chat previews with last message
chats.result?.forEach(chat => {
  console.log(`${chat.clientName}:`);

  if (chat.lastMessage) {
    console.log(`  Last: "${chat.lastMessage.text}"`);

    const date = new Date(chat.lastMessage.addTimestamp!);
    console.log(`  Time: ${date.toLocaleString('ru-RU')}`);
  } else {
    console.log(`  (no messages yet)`);
  }
});
```

**Output:**
```
Алена:
  Last: "Спасибо "
  Time: 24.12.2025, 10:17:10

Иван:
  Last: "Доставку организует Вайлдберрис..."
  Time: 13.12.2025, 14:23:45
```

### Sorting Chats by Last Activity

```typescript
// Sort chats by most recent message
const sortedChats = chats.result
  ?.filter(chat => chat.lastMessage?.addTimestamp)
  .sort((a, b) => {
    const timeA = a.lastMessage?.addTimestamp ?? 0;
    const timeB = b.lastMessage?.addTimestamp ?? 0;
    return timeB - timeA;  // Newest first
  });

// Show 5 most recent chats
sortedChats?.slice(0, 5).forEach(chat => {
  const time = new Date(chat.lastMessage!.addTimestamp!);
  const timeAgo = getTimeAgo(time);

  console.log(`${chat.clientName} - ${timeAgo}`);
  console.log(`  "${chat.lastMessage!.text?.substring(0, 50)}..."`);
});
```

### Chat Dashboard Component

```typescript
interface ChatPreview {
  chatId: string;
  customerName: string;
  lastMessage: string;
  timestamp: Date;
  unread: boolean;
}

async function getChatPreviews(): Promise<ChatPreview[]> {
  const chats = await sdk.communications.getSellerChats();

  return chats.result
    ?.filter(chat => chat.lastMessage)
    .map(chat => ({
      chatId: chat.chatID!,
      customerName: chat.clientName!,
      lastMessage: chat.lastMessage!.text!,
      timestamp: new Date(chat.lastMessage!.addTimestamp!),
      unread: false  // TODO: implement unread tracking
    })) ?? [];
}

// Display in UI
const previews = await getChatPreviews();
previews.forEach(preview => {
  renderChatCard({
    title: preview.customerName,
    subtitle: preview.lastMessage,
    timestamp: preview.timestamp,
    badge: preview.unread ? 'NEW' : null
  });
});
```

## Migration Guide

### For Existing SDK Users

**No action required** - this is a backward-compatible addition.

**Optional Enhancement:**
If you want to use the new `lastMessage` field:

```typescript
// Before (still works)
const chats = await sdk.communications.getSellerChats();
chats.result?.forEach(chat => {
  console.log(chat.chatID, chat.clientName);
});

// After (with new field)
const chats = await sdk.communications.getSellerChats();
chats.result?.forEach(chat => {
  console.log(chat.chatID, chat.clientName);

  // NEW: Show last message
  if (chat.lastMessage) {
    console.log('  Last message:', chat.lastMessage.text);
  }
});
```

**Type Safety:**
TypeScript will auto-complete the new `lastMessage` field:
```typescript
chat.lastMessage?.text  // ✅ Type: string | undefined
chat.lastMessage?.addTimestamp  // ✅ Type: number | undefined
```
