- Types: `IncomesItem`, `StocksItem`, `OrdersItem`, `SalesItem`

### Rate Limit Coordination

**Critical Rate Limits**:
- Finances endpoints: 1 request/minute
- Analytics endpoints: 1 request/5 seconds
- Communications (Chat): 1 request/5 seconds
- Communications (Reviews/Q&A): 1 request/minute
- Reports endpoints: 1 request/minute

**Rate Limit Strategy for Examples**:
1. Sequential API calls with delays between modules
2. Document total execution time expectations
3. Show rate limit wait time in console output
4. Demonstrate graceful handling of 429 errors

### Data Correlation Techniques

**Matching Transactions to Orders**:
- Use `saleID` from SalesItem to match transaction records
- Match by amount and timestamp proximity
- Handle timing discrepancies (transactions may lag orders by hours/days)

**Product Performance Analysis**:
- Use `nmId` (product ID) as primary key across modules
- Correlate sales data (Reports) with analytics metrics
- Match product reviews (Communications) to sales performance

**Customer Service Prioritization**:
- Negative reviews (rating 1-2) = High urgency
- Unanswered questions >3 days = Medium urgency
- Unread chat messages = High urgency
- Combine scores for overall product attention score
