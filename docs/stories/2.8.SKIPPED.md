# Story 2.8: Orders FBW Module - Returns and Cancellations

---

## Status

**SKIPPED** - Endpoints do not exist in Wildberries API

---

## Reason for Skip

This story was defined in the PRD with the following acceptance criteria:

```
As a marketplace seller using FBW,
I want to manage returns and cancellations,
so that I can handle post-purchase workflows.

Acceptance Criteria:
1. getReturns(filters: ReturnFilters) method retrieves return requests
2. getReturnById(returnId: string) method retrieves return details
3. processReturn(returnId: string, decision: ReturnDecision) method approves/rejects return
4. getCancellations(filters: CancellationFilters) method retrieves cancellation requests
5. processCancellation(cancellationId: string, decision: CancellationDecision) method handles cancellation
...
```

**However, after analyzing the actual Wildberries API specification:**

### ❌ FBW Module (`07-orders-fbw.yaml`) Does NOT Contain:
- No return management endpoints
- No cancellation management endpoints
- Only contains 8 endpoints for warehouse planning and supply information

### ✅ Where Returns/Cancellations Actually Are:

**Returns:**
- Located in **Communications Module** (`09-communications.yaml`)
- Endpoint: `/api/v1/claims` - Customer return claims
- Will be implemented in Epic 3, Story 3.5-3.6

**Cancellations:**
- Located in **Orders FBS Module** (`03-orders-fbs.yaml`)
- Endpoint: `/api/v3/orders/{orderId}/cancel` - Cancel order (seller-initiated)
- Only applies to FBS (Fulfillment by Seller), not FBW
- Already covered in Story 2.6

### Why This Makes Sense:

**FBW (Fulfillment by Wildberries):**
- Seller ships to WB warehouse
- **Wildberries handles all customer interactions including returns**
- Seller only manages supplies TO the warehouse, not individual order returns
- Returns are processed through the Communications module (same for both FBS and FBW)

**FBS (Fulfillment by Seller):**
- Seller ships directly to customer
- **Seller can cancel orders before shipping** (via `/cancel` endpoint in FBS module)
- Returns still go through Communications module

### Resolution:

**Story 2.7** has been updated to cover ALL 8 FBW endpoints:
1. ✅ `getWarehouses()` - List WB warehouses
2. ✅ `getAcceptanceCoefficients()` - Acceptance coefficients (14 days)
3. ✅ `getAcceptanceOptions()` - Available warehouses & package types
4. ✅ `getTransitTariffs()` - Transit directions and pricing
5. ✅ `getSupplies()` - List supplies with filters
6. ✅ `getSupplyDetails()` - Single supply details
7. ✅ `getSupplyGoods()` - Goods in supply
8. ✅ `getSupplyPackage()` - Package/box information

**FBW Module is COMPLETE with Story 2.7.**
