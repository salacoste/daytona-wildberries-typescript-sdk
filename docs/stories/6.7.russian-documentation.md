# Story 6.7: Russian Documentation Integration

## Status

Ready for Review

## Story

**As a** Russian-speaking developer,
**I want** SDK documentation available in Russian,
**so that** I can learn the SDK in my native language.

1. Existing Russian translations (docs/ru/) migrated to VitePress locale structure
2. Russian homepage created with translated hero section and features
3. Russian Getting Started section (quickstart, tutorials) accessible under /ru/
4. Russian guides integrated (best practices, troubleshooting, configuration)
5. Russian FAQ and Glossary pages accessible
6. Translation glossary (docs/ru/TRANSLATION_GLOSSARY.md) referenced in navigation
7. "Translation outdated" banner system implemented for pages where EN > RU version
8. Algolia search configured to index Russian content with proper language detection

### Translation Outdated Banner Component

**Create `.vitepress/theme/components/TranslationOutdated.vue`:**
```vue
<script setup lang="ts">
import { computed } from 'vue';
import { useData } from 'vitepress';

const { page, frontmatter } = useData();

// Check if translation is outdated
const isOutdated = computed(() => {
  if (!frontmatter.value.lastUpdatedEN) return false;
  if (!frontmatter.value.lastUpdatedRU) return false;

  const enDate = new Date(frontmatter.value.lastUpdatedEN);
  const ruDate = new Date(frontmatter.value.lastUpdatedRU);

  return enDate > ruDate;
});

// Get English page URL
const englishUrl = computed(() => {
  return page.value.relativePath.replace(/^ru\//, 'en/');
});
</script>

<template>
  <div v-if="isOutdated" class="translation-outdated-banner">
    <span class="icon">⚠️</span>
    <span class="message">
      Этот перевод может быть устаревшим.
      <a :href="`/${englishUrl}`">Просмотреть актуальную английскую версию</a>
    </span>
  </div>
</template>

<style scoped>
.translation-outdated-banner {
  display: flex;
  align-items: center;
  gap: 0.75rem;
  padding: 1rem;
  margin: 1.5rem 0;
  background: var(--vp-c-yellow-soft);
  border: 1px solid var(--vp-c-yellow);
  border-radius: 8px;
}

.icon {
  font-size: 1.25rem;
}

.message {
  flex: 1;
  color: var(--vp-c-text-1);
}

.message a {
  color: var(--vp-c-brand);
  text-decoration: underline;
}
</style>
```


```json
{
  "index_name": "wildberries-sdk",
```

- Check language facets: `language:ru`

- Solution: Verify file paths match /ru/ structure

**Issue 3: Translation outdated banner not showing**
- Solution: Verify frontmatter dates (lastUpdatedEN, lastUpdatedRU)
- Check component import in theme

**Issue 4: Language switching doesn't preserve context**
- Solution: Verify Russian page exists at same path as English
- Implement fallback for missing pages

**Issue 5: Russian characters display incorrectly**
- Solution: Verify UTF-8 encoding in markdown files
- Check HTML meta charset: `<meta charset="UTF-8">`
