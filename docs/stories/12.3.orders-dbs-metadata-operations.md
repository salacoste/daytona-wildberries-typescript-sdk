## Story

**As a** Wildberries seller using DBS fulfillment,
**I want** to manage order metadata (marking codes, IMEI, UIN, GTIN, customs declarations) through the SDK,
**so that** I can comply with regulatory requirements for marked goods and imported products.

---

## Context

### Background

DBS orders may require specific metadata for regulatory compliance. The `requiredMeta` field in new orders indicates which metadata must be provided before the order can proceed. This is critical for:

- **Chestniy Znak (SGTIN)**: Mandatory marking system for certain product categories (tobacco, pharmaceuticals, shoes, etc.)
- **IMEI**: Required for mobile devices
- **UIN**: Unique Identification Number for specific regulated goods
- **GTIN**: Global Trade Item Number required for goods sold in Belarus
- **Customs Declaration (GTD)**: Required for imported goods

**Business Rules**:
1. Metadata can only be added when order is in `confirm` status
2. The `requiredMeta` field in order response shows which metadata is required
3. If `requiredMeta` is empty, no metadata is needed for that order
4. Each order can have only one value per metadata type (except SGTIN which allows 1-24 codes)

### Technical Context

**API Documentation**: `wildberries_api_doc/04-orders-dbs.yaml`
**Base URL**: `https://marketplace-api.wildberries.ru`

**Key OpenAPI Paths**:
```yaml
GET  /api/v3/dbs/orders/{orderId}/meta                  # Get metadata
DELETE /api/v3/dbs/orders/{orderId}/meta?key=           # Delete metadata
PUT  /api/v3/dbs/orders/{orderId}/meta/sgtin            # Set marking codes
PUT  /api/v3/dbs/orders/{orderId}/meta/uin              # Set UIN
PUT  /api/v3/dbs/orders/{orderId}/meta/imei             # Set IMEI
PUT  /api/v3/dbs/orders/{orderId}/meta/gtin             # Set GTIN
PUT  /api/v3/dbs/orders/{orderId}/meta/customs-declaration  # Set customs number
```

**Rate Limits** (from Swagger):

| Operation | Limit | Interval | Burst |
|-----------|-------|----------|-------|
| GET /meta | 300 req/min | 200ms | 20 |
| DELETE /meta | 300 req/min | 200ms | 20 |
| PUT /meta/* (all set methods combined) | 1000 req/min | - | - |

**Important**: The 1000 req/min limit is SHARED across all PUT metadata methods (sgtin, uin, imei, gtin, customs-declaration).

  ```typescript
  import { WildberriesSDK } from '../src';

  async function processOrdersWithMetadata() {
    const sdk = new WildberriesSDK({
      apiKey: process.env.WB_API_KEY
    });

    try {
      // 1. Get new orders
      console.log('Fetching new DBS orders...');
      const { orders } = await sdk.ordersDBS.getNewOrders();
      console.log(`Found ${orders.length} new orders`);

      for (const order of orders) {
        console.log(`\nProcessing order ${order.id}:`);
        console.log(`  Required metadata: ${order.requiredMeta.join(', ') || 'none'}`);

        // Skip orders without metadata requirements
        if (!order.requiredMeta.length) {
          console.log('  No metadata required, skipping...');
          continue;
        }

        // 2. Confirm order to enable metadata
        console.log('  Confirming order...');
        await sdk.ordersDBS.confirmBulk([order.id]);

        // 3. Set required metadata
        for (const metaKey of order.requiredMeta) {
          switch (metaKey) {
            case 'sgtin':
              console.log('  Setting marking code (Chestniy Znak)...');
              await sdk.ordersDBS.setSgtin(order.id, ['010460406000600021N4N57RSCBUZTQ']);
              break;
            case 'imei':
              console.log('  Setting IMEI...');
              await sdk.ordersDBS.setImei(order.id, '123456789012345');
              break;
            case 'uin':
              console.log('  Setting UIN...');
              await sdk.ordersDBS.setUin(order.id, '1234567890123456');
              break;
            case 'gtin':
              console.log('  Setting GTIN...');
              await sdk.ordersDBS.setGtin(order.id, '4607000000000');
              break;
            case 'customsDeclaration':
              console.log('  Setting customs declaration...');
              await sdk.ordersDBS.setCustomsDeclaration(order.id, '10129050/010120/0001234');
              break;
          }
        }

        // 4. Verify metadata
        const meta = await sdk.ordersDBS.getMeta(order.id);
        console.log('  Metadata set successfully:', Object.keys(meta.meta));

        // 5. Move to delivery
        console.log('  Moving to delivery...');
        await sdk.ordersDBS.deliverBulk([order.id]);
      }

      console.log('\nAll orders processed!');
    } catch (error) {
      console.error('Error:', error.message);
    }
  }

  processOrdersWithMetadata();
  ```

### Compliance Context

**Chestniy Znak (Honest Sign)**:
- Russian national product traceability system
- Mandatory for: tobacco, pharmaceuticals, shoes, cameras, tires, perfumes, clothes, milk products
- SGTIN format: 01 + GTIN (14 digits) + 21 + Serial (variable)

**GTIN for Belarus**:
- Required for goods sold to Belarus customers
- 13-digit EAN barcode

**GTD (Customs Declaration)**:
- Required for imported goods
- Format: Registration number/Date code/Serial number
