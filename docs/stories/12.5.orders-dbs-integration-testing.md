## DBS Workflows for Examples

### Workflow 1: Standard DBS Order
```
1. getNewOrders()           - Get pending orders
2. getClientInfo()          - Get customer address/phone
3. confirmBulk([orderId])   - Start assembly
4. [prepare shipment]       - Physical preparation
5. deliverBulk([orderId])   - Mark as in delivery
6. [deliver to customer]    - Physical delivery
7. receiveBulk(code)        - Customer confirms receipt
   OR rejectBulk(code)      - Customer refuses
```

### Workflow 2: B2B Order with Invoice
```
1. getNewOrders()           - Get pending orders
2. getB2BInfo([orderId])    - Get organization data (INN, KPP, orgName)
3. [generate invoice]       - Create invoice with org data
4. confirmBulk([orderId])   - Start assembly
5. deliverBulk([orderId])   - Mark as in delivery
6. receiveBulk(code)        - Complete delivery
```

### Workflow 3: Regulated Products (Marking)
```
1. getNewOrders()           - Check requiredMeta field
2. setSgtin(orderId, codes) - Set Chestniy Znak codes
   OR setImei(orderId, imei) - Set device IMEI
   OR setGtin(orderId, gtin) - Set GTIN (Belarus)
3. confirmBulk([orderId])   - Assembly with metadata
4. deliverBulk([orderId])   - Delivery
5. receiveBulk(code)        - Complete
```

## Dev Notes

### Rate Limit Summary (from Swagger)

| Operation Category | Rate Limit | Interval | Burst |
|-------------------|------------|----------|-------|
| Core read (getNewOrders, getOrders, getClientInfo) | 300/min | 200ms | 20 |
| Bulk status read (getStatusesBulk) | 300/min | 200ms | 20 |
| Bulk status write (confirm/deliver/receive/reject/cancel) | 100/min | 600ms | 20 |
| Metadata read (getMeta) | 300/min | 200ms | 20 |
| Metadata write (setSgtin, setImei, etc.) | 1000/min | combined | - |
| B2B info | 300/min | 200ms | 20 |
| Deprecated methods | Same as bulk equivalents | - | - |

**Note**: 409 Conflict errors count as 10 requests toward rate limit.

### SDK Property Naming

Following existing patterns:
- `ordersFBS` - FBS module (existing)
- `ordersFBW` - FBW module (existing)
- `ordersDBS` - DBS module (new)

### Migration Guide Content

Document transition from deprecated single-order methods to bulk methods:
- `confirm(orderId)` -> `confirmBulk([orderId])`
- `deliver(orderId)` -> `deliverBulk([orderId])`
- `receive(orderId, code)` -> `receiveBulk([{ orderId, code }])`
- `reject(orderId, code)` -> `rejectBulk([{ orderId, code }])`
- `cancel(orderId)` -> `cancelBulk([orderId])`
- `getStatuses(orderIds)` -> `getStatusesBulk(orderIds)`

Deprecation deadline: 13.04.2026
