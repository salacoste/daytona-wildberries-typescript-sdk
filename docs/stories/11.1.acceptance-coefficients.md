## User Story

**As a** пользователь SDK,
**I want** получать коэффициенты приёмки для складов на ближайшие 14 дней,
**so that** я могу планировать поставки на склады WB с учётом стоимости приёмки.

---

## Business Context

Коэффициент приёмки — ключевой показатель для планирования поставок:
- `-1` — приёмка недоступна (склад закрыт для поставок)
- `0` — бесплатная приёмка (оптимальное время для поставки)
- `1+` — множитель стоимости приёмки (чем выше, тем дороже)

Приёмка доступна только при: `coefficient` = 0 или 1 **И** `allowUnload` = true

---

## Technical Specification

### API Endpoint

```
GET https://supplies-api.wildberries.ru/api/v1/acceptance/coefficients
```

**Query Parameters:**
- `warehouseIDs` (optional) — Фильтр по ID складов, через запятую

**Rate Limit:** 6 req/min, интервал 10 секунд

### Response Schema

```typescript
interface ModelsAcceptanceCoefficient {
  date: string;                      // Дата в формате YYYY-MM-DD
  coefficient: number;               // -1 | 0 | 1 | 2 | ... | 10
  warehouseID: number;               // ID склада
  warehouseName: string;             // Название склада
  allowUnload: boolean;              // Разрешена ли разгрузка
  boxTypeName: string;               // Тип упаковки
  boxTypeID?: number;                // 2=Короба, 5=Монопаллеты, 6=Суперсейф
  storageCoef?: string;              // Коэффициент хранения (%)
  deliveryCoef?: string;             // Коэффициент логистики (%)
  deliveryBaseLiter?: string;        // Базовая ставка логистики ₽/л
  deliveryAdditionalLiter?: string;  // Доп. ставка логистики ₽/л
  storageBaseLiter?: string;         // Базовая ставка хранения ₽/л/день
  storageAdditionalLiter?: string;   // Доп. ставка хранения ₽/л/день
  isSortingCenter?: boolean;         // Сортировочный центр
}
```

## Example Usage

```typescript
import { WildberriesSDK } from 'wb-api-sdk';

const sdk = new WildberriesSDK({ apiKey: 'your-api-key' });

// 1. Получить все коэффициенты
const allCoefficients = await sdk.ordersFbw.getAcceptanceCoefficients();

// 2. Фильтр по складу
const krasnodarCoefs = await sdk.ordersFbw.getAcceptanceCoefficients({
  warehouseIDs: '218623'  // Краснодар (Тихорецкая)
});

// 3. Найти оптимальные дни для поставки
const optimalDays = allCoefficients.filter(c =>
  c.coefficient === 0 &&
  c.allowUnload === true &&
  c.boxTypeName === 'Короба'
);

console.log('Дни с бесплатной приёмкой коробов:');
optimalDays.forEach(day => {
  console.log(`${day.date} - ${day.warehouseName}`);
});

// 4. Анализ затрат по складу
const warehouseAnalysis = krasnodarCoefs
  .filter(c => c.boxTypeName === 'Короба')
  .map(c => ({
    date: c.date,
    acceptanceMultiplier: c.coefficient,
    deliveryCoef: c.deliveryCoef,
    storageCoef: c.storageCoef,
    canDeliver: c.allowUnload && c.coefficient >= 0
  }));
```
