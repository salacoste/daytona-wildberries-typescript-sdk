# Story 6.10: SEO Optimization and Meta Tags

## Status

Draft

## Story

**As a** developer searching for Wildberries SDK solutions,
**I want** the documentation site optimized for search engines,
**so that** I can discover the SDK through Google search.

## Acceptance Criteria

1. Meta tags configured for all pages (title, description, keywords)
2. Open Graph tags added for social sharing (og:title, og:description, og:image)
3. Twitter Card tags added (twitter:card, twitter:title, twitter:description)
4. Sitemap.xml generated automatically during VitePress build
5. robots.txt configured to allow crawling (all pages indexable)
6. Canonical URLs configured for all pages (prevent duplicate content)
7. Structured data markup added (JSON-LD for SoftwareApplication)
8. SEO-friendly URLs implemented (kebab-case, no file extensions)
9. Alt text required for all images (automated validation)
10. Lighthouse SEO score ≥90

**IV1: SEO Tag Validation**
- Meta tags present on all pages (automated check)

### Image Alt Text Validation

**Validation script: scripts/validate-image-alt-text.js**

```javascript
import fs from 'fs';
import path from 'path';
import { glob } from 'glob';

const docsDir = path.resolve('docs');
const markdownFiles = glob.sync('**/*.md', { cwd: docsDir });

let errors = 0;

for (const file of markdownFiles) {
  const filePath = path.join(docsDir, file);
  const content = fs.readFileSync(filePath, 'utf8');

  // Match images: ![alt text](url)
  const imageRegex = /!\[(.*?)\]\((.*?)\)/g;
  let match;

  while ((match = imageRegex.exec(content)) !== null) {
    const altText = match[1];
    const imageUrl = match[2];

    if (!altText || altText.trim() === '') {
      console.error(`❌ Missing alt text: ${file}`);
      console.error(`   Image: ${imageUrl}`);
      errors++;
    }
  }
}

if (errors > 0) {
  console.error(`\n❌ Found ${errors} images without alt text`);
  process.exit(1);
} else {
  console.log('✅ All images have alt text');
}
```

**Add to package.json:**

```json
{
  "scripts": {
    "validate:images": "node scripts/validate-image-alt-text.js"
  }
}
```

**Alt text best practices:**
- Describe image content (not "image" or "screenshot")
- Keep under 125 characters
- Include context relevant to content
- Skip decorative images (use empty alt: `![](image.png)`)

### Common Issues and Solutions

**Issue 1: Open Graph image not displaying**
- Solution: Verify absolute URL (not relative)
- Check image size (1200x630px)
- Test with Facebook Sharing Debugger
- Clear Facebook cache if needed

**Issue 2: Sitemap.xml not generating**
- Solution: Verify VitePress sitemap configuration
- Check build output (.vitepress/dist/sitemap.xml)
- Ensure hostname is correct

**Issue 3: Lighthouse SEO score < 90**
- Solution: Review failing audits in Lighthouse report
- Fix specific issues (missing meta tags, alt text, etc.)
- Re-run Lighthouse after fixes

**Issue 4: Canonical URLs not working**
- Solution: Verify transformPageData function
- Check absolute URLs (not relative)
- Inspect page source for <link rel="canonical">

**Issue 5: robots.txt returning 404**
- Solution: Verify file in docs/public/robots.txt
- Check VitePress copies public/ to dist root
- Test on deployed site (not localhost)

**Issue 6: Google Search Console verification fails**
- Solution: Ensure verification file in docs/public/
- Wait for deployment to complete
- Try alternative verification method (DNS)
