# 8.2: Finances Module - Add delivery_method Field

## Status

**✅ COMPLETED** - December 2024

---

## Summary

Added new `delivery_method` field to the `DetailReportItem` type in the Finances module. This field indicates the fulfillment method used for each sale in the realization report.

---

## Background

Wildberries updated their API endpoint `/api/v5/supplier/reportDetailByPeriod` to include a new `delivery_method` field that specifies how each order was fulfilled.

**API Documentation**: https://dev.wildberries.ru/openapi/financial-reports-and-accounting#tag/Finansovye-otchyoty

---

## Changes Made

### 1. YAML Documentation Update

**File**: `wildberries_api_doc/13-finances.yaml`

Added new field to `DetailReportItem` schema:

```yaml
delivery_method:
  type: string
  description: |
    Способ продажи и тип товара.
    Возможные значения:
      - `FBS` — продажа со склада продавца
      - `FBW` — продажа со склада Wildberries
      - `DBS` — доставка силами продавца

```

### 2. SDK Types Update

**File**: `src/types/finances.types.ts`

Added TypeScript definition:

```typescript
/**
 * Способ продажи и тип товара.
 * Возможные значения:
 * - `FBS` — продажа со склада продавца
 * - `FBW` — продажа со склада Wildberries
 * - `DBS` — доставка силами продавца
 */
delivery_method?: string;
```

---

## Delivery Method Values

| Value | Description (EN) | Description (RU) |
|-------|------------------|------------------|
| `FBS` | Fulfillment by Seller | Продажа со склада продавца |
| `FBW` | Fulfillment by Wildberries | Продажа со склада Wildberries |
| `DBS` | Delivery by Seller | Доставка силами продавца |

## Usage Example

```typescript
import { WildberriesSDK } from 'daytona-wildberries-typescript-sdk';

const sdk = new WildberriesSDK({ apiKey: process.env.WB_API_KEY! });

// Get sales report with delivery method breakdown
async function getSalesByDeliveryMethod() {
  const report = await sdk.finances.getReportDetailByPeriod({
    dateFrom: '2024-01-01',
    dateTo: '2024-01-31'
  });

  // Group by delivery method
  const byMethod = new Map<string, number>();

  report.forEach(item => {
    const method = item.delivery_method || 'unknown';
    const current = byMethod.get(method) || 0;
    byMethod.set(method, current + (item.ppvz_for_pay || 0));
  });

  console.log('Revenue by Delivery Method:');
  byMethod.forEach((amount, method) => {
    console.log(`  ${method}: ${amount.toLocaleString()}₽`);
  });

  return byMethod;
}

// Analyze fulfillment efficiency
async function analyzeFulfillmentMix() {
  const report = await sdk.finances.getReportDetailByPeriod({
    dateFrom: '2024-01-01',
    dateTo: '2024-01-31'
  });

  const stats = {
    FBS: { count: 0, revenue: 0 },
    FBW: { count: 0, revenue: 0 },
    DBS: { count: 0, revenue: 0 }
  };

  report.forEach(item => {
    const method = item.delivery_method as 'FBS' | 'FBW' | 'DBS';
    if (method && stats[method]) {
      stats[method].count++;
      stats[method].revenue += item.ppvz_for_pay || 0;
    }
  });

  const total = stats.FBS.count + stats.FBW.count + stats.DBS.count;

  console.log('Fulfillment Mix Analysis:');
  Object.entries(stats).forEach(([method, data]) => {
    const percentage = total > 0 ? ((data.count / total) * 100).toFixed(1) : 0;
    console.log(`  ${method}: ${data.count} orders (${percentage}%), ${data.revenue.toLocaleString()}₽`);
  });
}
```
